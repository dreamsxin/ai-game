# 玉山 · 雾中坠星

根据小说《玉山卷_重制》的第一卷开篇制作的 Godot 4 固定视角 3D 水墨风可玩序章。项目使用原创程序化几何、材质和 shader，不依赖外部素材。

## 启动

用 Godot 4.3 或更新版本打开本目录中的 `project.godot`，运行主场景即可。当前验证版本为 Godot 4.6.2。

## MVP 闭环

1. 推进开场对话，进入雾谷探索阶段。
2. 移动到坠星旁按 `E` 触碰，触发星核入体与读线教程。
3. 噬灵进入战斗；按住空格蓄力，靠近后左键出刀，命中三次击败敌人。
4. 生命归零进入失败状态；击败敌人后前往神殿平台完成序章。
5. 序章完成或失败后按 `R` 重新开始。

## 架构

- `scripts/game.gd`：主场景导演，负责场景/HUD组装、对话、游戏阶段状态机与目标交互。
- `scripts/player_controller.gd`：玩家移动输入与边界约束。
- `scripts/enemy_controller.gd`：敌人追击、近身伤害、受击与击败信号。
- `main.tscn` / `project.godot`：入口场景与运行配置。

游戏阶段为开场、探索、战斗、返回神殿、完成和失败。玩家与敌人组件不直接控制故事进度，结果通过状态/信号回传主流程。流程回归测试可运行：`E:/apk/tools/Godot/Godot_console.exe --headless --path D:/work/ai-game/yushan-ink --script res://scripts/mvp_flow_test.gd`。

## 操作

- `WASD`：移动
- `E`：互动 / 触碰坠星 / 抵达神殿
- `空格`：推进对话；战斗时按住读线蓄力
- `鼠标左键`：蓄力后出刀
- `R`：完成或失败后重新开始

## MVP 范围

这是基于小说开篇制作的可玩序章，不是完整 30 章游戏。MVP 验证叙事入口、探索互动、基础战斗、阶段切换、胜负结算与重开。角色模型与场景仍为程序化占位；存档、背包、任务系统、正式动画/美术和后续章节不在本轮范围。
