# 玉山 · 雾中坠星

根据小说《玉山卷_重制》第一卷开篇制作的 Godot 4 固定视角 3D 青绿山水风可玩序章。视觉取《千里江山图》的设色逻辑：石青、石绿、赭石、绢本暖底、泥金勾线，青墨勾轮廓。项目使用原创程序化几何、材质、shader 与合成音效，不依赖任何外部素材。

> 配色为风格化近似取色，并非文物数字复原。

## 启动

用 Godot 4.3 或更新版本打开 `project.godot`，运行主场景即可。当前验证版本为 Godot 4.6.2。

## MVP 闭环

1. 推进开场对话，进入雾谷探索阶段。
2. 移到坠星旁按 `E` 触碰，星核入体并触发读线教程。
3. 噬灵进入战斗：按住 `空格` 读线蓄力（有负荷代价，脚下显青金光环），靠近后左键出刀，三次有效命中击败敌人。敌人会周期性蓄力扑击。
4. 生命归零进入失败状态；击败敌人后前往神殿平台按 `E` 完成序章。
5. 完成或失败后按 `R` 重新开始。

有效出刀需 `读线 ≥ 45%`；蓄力时每秒消耗约 2.2 点负荷，呼应「引多少，身体就要承多少」。

## 架构

| 文件 | 职责 |
| --- | --- |
| `scripts/game.gd` | 主场景导演：场景/HUD 组装、对话、阶段状态机、目标交互、青绿后处理 |
| `scripts/ink_palette.gd` | 统一调色板，所有色值集中于此，换风格只改这一个文件 |
| `scripts/player_controller.gd` | 玩家移动输入与边界约束 |
| `scripts/enemy_controller.gd` | 敌人追击、蓄力扑击、受击与击败信号 |
| `scripts/audio_synth.gd` | 运行时合成 PCM 短音，游戏侧只调用语义名 |
| `scripts/mvp_flow_test.gd` | 无界面流程回归测试 |
| `main.tscn` / `project.godot` | 入口场景与运行配置 |

阶段为开场、探索、战斗、返回神殿、完成、失败。玩家与敌人组件不直接推进剧情，结果通过状态与信号回传主流程。shader 的分级设色由调色板通过 uniform 注入，「读线蓄力」会驱动画面青金辉光与泥金勾线。

## 视觉实现

- **勾线填彩**：屏幕边缘检测生成青墨轮廓，高反差山脊叠泥金。
- **随类赋彩**：按明度把画面映射到石青 → 石绿 → 绢黄 → 泥金；暖色像素额外保留金调。
- **近绿远青**：画面上部渐染淡石青，无硬边；3D 远山在玩家向神殿移动、镜头前移时逐层展开。
- **绢本质感**：薄暖底、经纬细纹与纸面颗粒，配合环境雾做留白。
- **场景**：层叠六边锥峰配赭石山脚、淡青江水、石绿松林、赭石古建与泥金坠星；人物素绢衣加石绿披风保证可读。

## 操作

- `WASD`：移动
- `E`：互动 / 触碰坠星 / 抵达神殿
- `空格`：推进对话；战斗时按住读线蓄力
- `鼠标左键`：蓄力后出刀
- `R`：完成或失败后重新开始

## 范围

这是可玩序章，不是完整 30 章游戏。当前已验证叙事入口、探索互动、蓄力战斗、阶段切换、胜负结算与重开。角色与场景仍为程序化占位；存档、背包、任务系统、正式动画/美术、后续章节与音效混音仍未实现。
