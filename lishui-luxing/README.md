# 丽水山水图 · 千里江山风格旅行导览

一张用《千里江山图》矿物色画成的 3D 丽水旅行导览图。九县 37 处景点按经纬度落点，
点印章就能看到**它在哪、主要看点是什么、有什么游玩 tips**。

```bash
npm run dev:lishui-luxing   # http://127.0.0.1:4197
```

## 怎么用

- **转/缩/平移**：左键拖动旋转，滚轮缩放，右键（或双指）平移
- **点印章**：弹出题跋卡 —— 头衔、建议时长、时令、门票形态、怎么到、看点、tips、顺路还有哪几处
- **筛选**：按九县（莲都／龙泉／青田／缙云／遂昌／松阳／云和／庆元／景宁）、按分类（峰峦叠翠／江湖烟波／古村人家／器物匠作／碑刻遗迹／田畴林泉／畲乡风物）、按时令，或直接搜看点关键词（「云海」「廊桥」「青瓷」「梯田」都能搜到）
- **行程**：6 条线路，选中后整条线框进画面并画出缎带与编号印章，站点可逐个点开
- **卷面**：全卷／缙云／瓯江／松古／南脊／平铺六个机位，晴卷／烟雨／暮金三套光照

## 画风是怎么来的

三件事合起来才像《千里江山图》，少一件就变回普通地形图：

1. **天不是蓝的。** 画里的"天"是绢本身，所以天空用绢黄渐变，雾也是绢色 ——
   远山淡入绢底，就是画里留白的做法。
2. **高程色带就是画风。** 谷底绢黄赭石 → 山腰石绿 → 峰顶石青。
   丽水平均海拔约六百米，所以石青压到 1300 米以上才出现，否则整个市糊成一片蓝。
3. **标注是绢签与印章。** 景点名写在绢色小牌上（墨字 + 赭石细边），
   类别与行程站序用朱砂印章（白边白字），都是画上题写的两种方式。

界外不裁断而是"退场"：高度随离市界的距离迅速落到绢底，颜色再洗淡七成半，
主体是丽水，四周像留白 —— 这比在边界上切一刀自然得多。

## 分层

判定层（`src/atlas/`）没有 DOM 也没有 three，可以直接被 `node --test` 吃掉；
表现层（`src/scene/`）只读它、不改它。

- `atlas/spots.js` — 37 处景点的事实表：坐标、乡镇、头衔、时长、时令、看点、tips、交通
- `atlas/geo.js` — 市界轮廓、46 个高程控制点、3 处水库、4 条水系、9 个县城
- `atlas/terrain.js` — 高程场：反距离加权插值 + 三档噪声，再把水库与江切进去
- `atlas/projection.js` / `routes.js` / `query.js` — 投影；行程表；筛选、搜索、统计、附近、行程展开
- `scene/atlasGroup.js` — 地形、各自高度的水面、市界墨线、印章标记、行程缎带、县名
- `scene/labels.js` — 绢签与朱砂印章的 canvas 贴图、水面波纹贴图
- `scene/createScene.js` — 绢色天光、暖调光照、轨道控制、拾取、镜头飞行

## 三个踩过的坑

**水面不能用一张。** 丽水没有海，水各在不同海拔上：云和湖 184m、千峡湖 160m、
南明湖 50m，瓯江从龙泉的 190m 一路降到温溪的 8m。所以每处水体自己记住 `surface`，
地形按这个高度下切，表现层每个湖一张面、每条江一条带 —— 沿海地图那种"一张海平面盖全图"的做法在这里直接不成立。

**高程控制点必须成对给：山峰 + 河谷。** 只放山峰的话，反距离加权会把浙南插成一块连续高原，
山谷（人、公路、古村真正待的地方）全被填平。修法是把县城、盆地、河谷的真实低值也放进 `RELIEF`，
插值指数提到 4 让影响局部化，后来又补了龙泉屏南、庆元黄田、景宁英川几处中间谷地，
才把那片"一大块蓝"拆成山脊与山谷。

**sprite 的 scale 不能 setScalar。** 印章是屏幕固定字号的 sprite，基准 scale 只有 0.03；
hover 放大时写成 `setScalar(1.3)` 会把基准冲掉，印章瞬间涨到糊住整屏（第一次跑就是这个样子）。
正确写法是把基准 scale 存下来，放大时乘在基准上。

## 数据口径

坐标是主入口或标志景点的近似值，用于**定位**而不是导航。丽水多山路，
直线距离常只有实际车程的一半，所以行程卡只说"直线"。
门票与预约规则变得快，`ticket` 只写形态（免费／分景区另收／船票为主）不写金额；
头衔只写确认的实称（5A／4A／全国重点文物／世界灌溉工程遗产／全球重要农业文化遗产）。

## 验证

```bash
npm run test:lishui-luxing
npm run build:lishui-luxing
```

33 条测试守四件事：

1. **每处都答得上问题** —— 至少 3 条看点、3 条 tips，坐标必须落在市界多边形之内，
   九县与七个分类都有条目，每个筛选选项都选得出东西
2. **地形骨架** —— 市内抽样平均海拔 >350m（九山半水半分田），黄茅尖一带 >1500m，
   瓯江出境处 <260m；界外标记为界外但仍有地形
3. **水体各在自己的高度上** —— 三处水库的 surface 互不相同，瓯江上游水面远高于下游，
   沿河插值落在两端之间，水库里留得出岛
4. **行程是顺路的** —— 相邻两站直线 ≤80km、平均每天 ≤45km（山路按直线的两倍估），
   六条线覆盖九县中的七个以上
