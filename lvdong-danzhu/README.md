# 律动弹珠 · 打砖块消除

手机触屏优先的打砖块×弹珠消除。挡板反弹球去打上方的弹珠墙，同色三连整组消并穿墙连消，
墙按节拍一行行往下压，踩着拍子接球攒律动倍率，六关递进。

## 玩法

- 在场地上拖动移动挡板，点一下发球；球在飞行中再点一下换挡板上膛的颜色，也可以直接点下方的颜色按钮。
- 键盘：左右方向键移动挡板，`Space`/`Enter`/`↑` 发球与换色，`Esc`/`P` 暂停。
- 球带颜色，撞到同色弹珠时看连通块：三颗以上整组消掉，球不反弹直接穿过去，一趟飞行里连消越多倍率越高（每环 +0.5，最高 4 倍）。
- 同色但凑不满三颗只崩掉那一颗；异色撞两下才砸碎，第一下只留裂纹，用来给同色组开路。
- 弹珠墙挂在顶部，消掉支撑点后挂不住的整片弹珠会掉下来另算分。
- 挡板接球的瞬间落在节拍窗口内就攒一层律动，倍率每层 +0.1、最高 2 倍，踩空归零。
- 每隔若干拍挤进一行新弹珠，波次下完后只剩清场；墙压过底线或三条命用光就结束。
- 关卡目标只决定星级，清空整面墙才算过关。

## 结构

`src/game/` 是纯逻辑层，不碰 DOM：`rules.js` 集中场地尺寸、物理常量与计分，
`marbles.js` 定义五种颜色，`grid.js` 管同色连通块、悬空判定、整墙下压与补行，
`levels.js` 是六关的球速、颜色数、BPM 与波次，`physics.js` 是分子步的球体运动与碰撞
（撞击结果交回上层决定是反弹还是穿过），`simulation.js` 是定步长状态机（节拍时钟 → 挡板 → 飞行 → 判定），
`input.js` 把键盘和手势归一成同一份输入，`layout.js` 是渲染与输入共用的格子换算。

`src/scene/` 是表现层，不写回模拟状态：`render.js` 用 Canvas 2D 画弹珠墙、球、挡板、节拍环和消除余光，
`readout.js` 派生 HUD 文案与进度。

这条边界让确定性回放成立：同一个 seed 加同一串输入，模拟结果逐字段一致，测试因此不需要浏览器。
`test/playthrough.test.js` 让跟球机器人把六关各打三个 seed，关卡数据一旦调成清不完的死关就会被测出来。
