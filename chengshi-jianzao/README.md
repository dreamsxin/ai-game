# 天际营造 · Skyline Works

3D 城市建造师。你是市长：从城门那格路开始铺街，配平住宅、岗位、电力和环境分，把人口做到关卡目标。

## 玩法

- **路先行**：所有建筑都要贴着一条能连回城门的路，断头路不算通车。
- **住宅配岗位**：住宅出人，商铺和工厂出岗位，一个岗位养 2.2 个居民，任一短缺都会卡住人口。
- **电要够**：全城用电超过供电就整城跳闸，耗电建筑一起停摆（场景里会集体压暗）。
- **环境要管**：工厂电厂压低周边环境分，低于 40 分居民开始搬走；公园、林地和水面把分补回来。
- **钱会流走**：每栋楼收月度维护费，税收随人口和环境分浮动，连续 4 个月赤字就破产。

六关递进：落基镇 → 双溪口 → 工坊区 → 绿荫台 → 临港城 → 天际都。达标月份在 par 之内是三星。

## 操作

- 在地图上按住拖动，可以连着铺路或连着建同一种建筑；同一格只结算一次。
- 底部工具栏选建筑，最右边是拆除（拆迁费 4）。
- 时间默认暂停，按播放键开始走月，可切 2 倍速。
- 键盘：`1`~`6` 选建筑、`B` 拆除、`,` `.` 前后切工具、空格暂停、`Q` `E` 转视角、`+` `-` 缩放、`R` 重开本关。

## 反馈

这一关的状态机没有 effects 数组，一次操作只是换出一个新 state。所以音效由「前后两个状态」派生：
`revision` 涨了是真盖上了、`month` 涨了是走过一个月、都没涨却多出一句 `notice` 就是被拒了。
这三件事此前在感官上完全一样——盖成了和钱不够都只是右上角闪一行字。

- 落子声按工具分：铺路最轻（拖着画一秒能响十几次）、盖房是夯土的闷响、拆迁是碾碎。
- 钱不够或位置不合法给一声闷的下滑；同一句提示重复撞上不再响，拖着画路不会一直念「钱不够」。
- 每走一个月响一记极轻的月历，紧接着按严重程度补一条月报：
  全城跳闸（低频嗡鸣）> 有人搬走 > 本月赤字 > 有人迁入，和 HUD 上那句话念的是同一条优先级。
- 被拒、跳闸、达标、破产会震一下，每盖一格不震。
- 左侧「音效」可以随时静音，选择记在本地；静音状态下不会建出音频线程。
- 结算面板：破纪录横幅、三颗星逐颗弹出、按星数给一句点评、总星带分母。
- 音效全部由 WebAudio 现场合成，不引任何音频文件；`prefers-reduced-motion` 下庆祝动画自动关掉。

## 代码结构

- `src/game/rules.js`：地形、建筑目录、关卡与评分的唯一真源。
- `src/game/city.js`：网格、落位判定、从城门出发的路网 BFS。
- `src/game/economy.js`：市政结算（供电、床位、岗位、环境分）与月报。
- `src/game/simulation.js`：状态机，`build` / `tick` / 达标与破产判定。
- `src/scene/`：Three.js 渲染、体块模型（纯数组，可单测）、文案与镜头换算、程序化音效。

`src/scene/audio.js` 的分工和别处一致：`soundsFor(prev, next)` / `vibrationFor(prev, next)` 是纯函数，能单测；
只有 `createAudio` 碰 `AudioContext`，而且懒建——静音开局一个音频节点都不建。
换关和重开靠「关号变了」或「月份／revision 倒退」识别，比比对 `level` 对象引用可靠：
`restartLevel` 换回来的是同一个 `level`。


关卡地图由 seed 决定，同一个 seed 永远长出同一张图，所以「这一关换张新地图」只是换 seed。
