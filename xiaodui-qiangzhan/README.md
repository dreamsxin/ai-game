# 小队枪战 · 3v3 团队射击

手机触屏优先的俯视角团队射击对战。你带两个队友打三个敌人，自由方向移动、双摇杆瞄准，
枪口有惯性、散布随状态变化，视线内的敌人会被软锁牵引，先到 15 分或三分钟结束时领先的一方获胜。

## 玩法

- 触屏：左半屏按下拖动是移动摇杆，任意方向自由跑；右半屏是瞄准摇杆，轻推只转枪口，推过一半自动开火。
- 键盘鼠标：`WASD` / 方向键移动，鼠标指向瞄准，左键开火，右键或 `Shift` 端稳，`R` 换弹，`Esc` / `P` 暂停。
- 瞄准辅助分两层：视线内、辅助锥内、13 格内的敌人会成为软锁目标，枪口被额外朝它牵引；偏角进锁定锥后准星和射线变金色，才算真咬住。
- 散布决定子弹落点：站定最准，跑动加惩罚，每开一枪抬枪，端稳会把散布整体收到三分之一，代价是脚步降到 55% 速度、枪口转得更慢。
- 伤害按距离衰减，9 格内满伤，18 格外只剩 55%；掩体挡子弹，队友不挡（没有友伤）。
- 地图是 20×24 的竖版对称掩体场，我方从下方三个点出生、敌方从上方出生，横向长廊把掩体串成可绕行的路线。
- 弹匣 25 发，打空自动换弹，换弹 1.6 秒内扣扳机无效。阵亡 3 秒后在离敌人最远的出生点复活。
- 计分：击杀给队伍加 1 分，玩家个人分按伤害和连杀累计，连杀每层多给 40 分。

## 结构

`src/game/` 是纯逻辑层，不碰 DOM：`rules.js` 集中场地尺寸、枪械数值、散布与计分公式，
`arena.js` 是掩体地图、圆形碰撞、分轴滑墙、采样射线与视线判定，
`aim.js` 是这款游戏的核心——枪口惯性（`turnToward`）、软锁选靶（`acquireTarget`）、牵引（`steerAim`）与准星读数，
`combat.js` 推进子弹并做线段-圆命中，`bots.js` 把「看得见谁→拉扯距离→顶完反应时间开枪」写成和玩家输入同构的意图，
`input.js` 把键盘、鼠标和双摇杆归一成同一份输入，`simulation.js` 是定步长状态机，`layout.js` 是渲染与输入共用的换算。

`src/scene/` 是表现层，不写回模拟状态：`render.js` 用 Canvas 2D 画掩体、单位朝向、弹道、散布锥、
锁定圈和双摇杆，`readout.js` 派生 HUD 文案。

玩家和机器人走同一条推进路径（意图 → `stepUnit`），随机只来自 seed 驱动的 PRNG，
所以同一个 seed 加同一串输入结果逐字段一致，测试不需要浏览器。
`test/playthrough.test.js` 直接拿机器人的意图当玩家输入代打整局，数值一旦失衡（打不中人、一边倒、卡进墙里）就会被测出来。
