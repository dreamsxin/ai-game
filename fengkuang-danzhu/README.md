# 疯狂打弹珠 · 回合制弹珠流

手机触屏优先的回合制打砖块。底部拖动瞄准，松手射出一整串弹珠去砸带血量的砖块，
吃加珠让弹珠越来越多，每回合结束砖块下压一行，压到底线就结束，玩法是无尽冲高分。

## 玩法

- 在场地上拖动瞄准，虚线是预瞄路线（会算左右墙的反弹），松手射出这一串弹珠。
- 键盘：左右方向键微调角度，`Space`/`Enter`/`↑` 开火，`Esc`/`P` 暂停。
- 砖上的数字是还要挨几下，撞一下掉一格血，血空才碎；血量越高颜色越偏红。
- 绿色加珠碰到就吃，弹珠总数 +1 且不挡路；这一串的数量在开火瞬间锁定，吃到的加珠下一回合才用上。
- 紫色炸弹砖碎的时候连带炸掉周围一圈，圈里再有炸弹就继续连锁，血再厚的砖也一起带走。
- 一回合里砸掉的砖越多，这回合后面的得分倍率越高，最高 2 倍。
- 全部弹珠落地后回合结束：发射点挪到第一颗落地弹珠的位置，砖块下压一行，回合数 +1。
- 每 10 回合进一个阶段，新砖血量和炸弹出现率跟着涨；砖块压过底线就结束。
- 一回合最多飞 14 秒，超时后弹珠会被拉向地面，回合一定收得住。

## 结构

`src/game/` 是纯逻辑层，不碰 DOM：`rules.js` 集中场地尺寸、物理常量、计分与难度曲线，
`bricks.js` 定义普通砖 / 炸弹砖 / 加珠三种格子，`grid.js` 管新行生成、整墙下压、掉血拆砖与炸弹连锁，
`aim.js` 是瞄准夹角与预瞄路线的纯几何，`physics.js` 是分子步的多球运动与碰撞
（撞击结果交回上层决定是反弹还是穿过），`simulation.js` 是定步长回合状态机（瞄准 → 逐颗放球 → 全部落地 → 下压），
`input.js` 把键盘和手势归一成同一份输入，`layout.js` 是渲染与输入共用的格子换算。

`src/scene/` 是表现层，不写回模拟状态：`render.js` 用 Canvas 2D 画砖墙血量、预瞄虚线、发射口、弹珠流和拆砖余光，
`readout.js` 派生 HUD 文案与危险度。

这条边界让确定性回放成立：同一个 seed 加同一串输入，模拟结果逐字段一致，测试因此不需要浏览器。
`test/playthrough.test.js` 让「瞄最低砖块」的机器人一路打到被压死，顺便盯住每个回合都必须在时限内收束、
不会出现弹珠卡住不落地的死局。
