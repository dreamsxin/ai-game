# 疯狂打弹珠 · 回合制弹珠流

手机触屏优先的回合制打砖块。底部拖动瞄准，松手射出一整串弹珠去砸带血量的砖块，
吃加珠让弹珠越来越多，每回合结束砖块下压一行，压到底线就结束，玩法是无尽冲高分。

## 玩法

- 在场地上拖动瞄准，虚线是预瞄路线（会算左右墙的反弹），松手射出这一串弹珠。
- 键盘：左右方向键微调角度，`Space`/`Enter`/`↑` 开火，`Esc`/`P` 暂停。
- 砖上的数字是还要挨几下，撞一下掉一格血，血空才碎；血量越高颜色越偏红。
- 绿色加珠碰到就吃，弹珠总数 +1 且不挡路；这一串的数量在开火瞬间锁定，吃到的加珠下一回合才用上。
- 紫色炸弹砖碎的时候连带炸掉周围一圈，圈里再有炸弹就继续连锁，血再厚的砖也一起带走。
- 一回合里砸掉的砖越多，这回合后面的得分倍率越高，最高 2 倍。
- 全部弹珠落地后回合结束：发射点挪到第一颗落地弹珠的位置，砖块下压一行，回合数 +1。
- 每 10 回合进一个阶段，新砖血量和炸弹出现率跟着涨；砖块压过底线就结束。
- 一回合最多飞 14 秒，超时后弹珠会被拉向地面，回合一定收得住。

## 反馈

这类玩法的爽点全在「一串球出膛、满场乱弹、连爆一片」这段听觉节奏上，此前一路上一声都没有：
砸掉一块砖和吃到一颗加珠在感官上完全一样。现在每件事都有一声，全部由 WebAudio 现场合成。

- **一颗颗出膛的「哒哒哒」**是这游戏最有标志性的声音，所以模拟层专门为它加了 `launch` 事件
  （每颗球离开发射口发一条）。它也是全表最轻的一条：一串二十颗就是二十下。
- **发射声跟着这一串的长度走**：每四颗上一个半音档，攒到一大串一听就知道这回合有分量。
- **砸碎的音高跟着这一下带走的砖数走**，炸弹连爆会明显更高。注意 `break.chain` 把加珠也算进去了，
  做音高映射用的是 `brickCount()`（只数真砖）。
- **加珠是一记清亮的铃**，和砸砖完全不在一个音色上——这是「下一串更长了」。
  炸弹连爆顺手带走的加珠不发 `pickup` 事件、只躺在 `break.cells` 里，`plusCount()` 把它捞了回来。
- **限流**：满场乱弹时擦碰声每秒能有几十条，`THROTTLE` 给 `hit`／`land`／`launch` 挂了最小间隔，
  关键反馈（发射、砸碎、加珠、下压、结束）一条都不限。这一层放在引擎里而不是 `soundsFor` 里，
  因为它跨帧才成立。
- **触感**只在结束和一次带走 4 块以上时给，弹珠全程都震手会麻。
- 右下角可静音，偏好写进 `localStorage`；静音开局连 `AudioContext` 都不建。
- 结算面板：破纪录挂徽章（拿开局那一刻的旧纪录比，而不是拿已被本局实时刷过的 `best` 比），
  下面一句 `rewardLabel` 说清下一局该往哪使劲；`prefers-reduced-motion` 下动效全停。

顺手修掉一处旧问题：`step()` 在非 `playing` 状态下原样返回，`effects` 会留着最后那一批事件，
而 App 每帧照旧 `notify`。结果是暂停时拆砖余光无上限堆积、结束音会一直循环。
现在拿 `elapsed`（只在推进时才涨）当 tick 标记，一批事件只派发一次。

## 结构

`src/game/` 是纯逻辑层，不碰 DOM：`rules.js` 集中场地尺寸、物理常量、计分与难度曲线，
`bricks.js` 定义普通砖 / 炸弹砖 / 加珠三种格子，`grid.js` 管新行生成、整墙下压、掉血拆砖与炸弹连锁，
`aim.js` 是瞄准夹角与预瞄路线的纯几何，`physics.js` 是分子步的多球运动与碰撞
（撞击结果交回上层决定是反弹还是穿过），`simulation.js` 是定步长回合状态机（瞄准 → 逐颗放球 → 全部落地 → 下压），
`input.js` 把键盘和手势归一成同一份输入，`layout.js` 是渲染与输入共用的格子换算。

`src/scene/` 是表现层，不写回模拟状态：`render.js` 用 Canvas 2D 画砖墙血量、预瞄虚线、发射口、弹珠流和拆砖余光，
`readout.js` 派生 HUD 文案与危险度，`audio.js` 里 `SOUNDS`／`soundsFor` 是纯数据与纯函数（能在 node 里单测），
只有 `createAudio` 碰 `AudioContext`，且第一次真要出声时才建。

这条边界让确定性回放成立：同一个 seed 加同一串输入，模拟结果逐字段一致，测试因此不需要浏览器。
`test/playthrough.test.js` 让「瞄最低砖块」的机器人一路打到被压死，顺便盯住每个回合都必须在时限内收束、
不会出现弹珠卡住不落地的死局。
