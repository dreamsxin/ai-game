# 菇星冒险 · 横版跳跃

手机触屏优先的 2D 横版跳跃闯关。经典玛丽式手感：跑跳、踩敌人、顶砖块、吃蘑菇变大、
星星无敌、旗杆过关，三关连打。角色和场景全部用 Canvas 2D 画出来，不含任何第三方素材。

## 玩法

- 左半屏按住拖动控制跑动，拖过 46px 变成奔跑；右半屏点一下起跳，按住不放跳得更高。
- 也可以用屏幕下方的按键：左、右、奔跑、跳。
- 键盘：`←`/`→` 或 `A`/`D` 移动，`Space`/`↑`/`Z` 跳跃，`Shift`/`X` 奔跑，`Esc`/`P` 暂停。
- 从上方踩敌人得分，一次滞空里连续踩不落地，分数按 100 / 200 / 400 / 800 / 1000 / 2000 递增。
- 乌龟第一脚踩成壳，再碰一下把壳踢出去；滑行的壳会撞飞路上的敌人，也会反弹回来撞到自己。
- 顶问号块出蘑菇（变大），顶星星块进入 8 秒无敌，顶砖块可以顶碎。
- 大身体被撞只会缩小并进入 1.8 秒无敌，小身体被撞、掉坑或超时都会掉一条命，共三条命。
- 摸到旗杆过关，剩余时间按每秒 50 分折成奖励。

## 本地运行

```bash
npm run dev:guxing-maoxian   # http://127.0.0.1:4178
npm run test:guxing-maoxian
npm run build:guxing-maoxian
```

## 结构

`src/game/` 是纯逻辑层，不碰 DOM：`rules.js` 定义重力、速度和计分，`tiles.js` 定义关卡
字符的含义，`levels.js` 用局部字符画拼出三张关卡图，`physics.js` 做 AABB 与瓦片的分轴碰撞，
`entities.js` 管敌人和道具的行为，`simulation.js` 是固定步长的状态机，`input.js` 把键盘、
手势和屏幕按键归一成同一份输入。

`src/scene/` 是表现层，不写回模拟状态：`render.js` 用 Canvas 2D 画视差背景、瓦片、角色、
敌人和粒子，并自己维护相机平滑与飘字；`readout.js` 派生 HUD 文案。

这条边界让确定性回放成立：同一关加同一串输入，模拟结果逐字段一致，测试因此不需要浏览器。
`test/playthrough.test.js` 还用一个「只会往右跑、遇坑遇刺就跳」的机器人跑完三关，
保证关卡地形不会被改出无法通过的跳跃。
