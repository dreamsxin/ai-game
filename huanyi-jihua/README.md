# 换翼计划 · 纵版射击

手机触屏优先的纵版飞行射击闯关。机翼是可拆卸的战术模块而不是升级项：
关卡开始前挑一只带上去，打不过就随时按下弃翼，用瞬间无敌换掉全部火力。16 关四章，
战机、敌人、弹幕全部用 Canvas 2D 画出来，不含任何第三方素材。

## 玩法

- 屏幕任意位置按住拖动走位（相对拖动，手指不会盖住船），火力一直是自动开的。
- **轻点一下弃翼**：机翼原地脱落，主机获得 1.05 秒无敌并加速一截，但只剩威力最小的小炮。
- 脱下来的翅膀飘得比主机快，往上追才接得回来——而往上正是敌人来的方向。飘出画面就真没了。
- 键盘：方向键或 `WASD` 走位，`Space`/`Z`/`X`/`J` 弃翼，`Esc`/`P` 暂停。
- **机翼同时是装甲**：带着翼被打中只掉翼（崩下来的翼还能抢回来），裸机被打中才掉命，共三条命。
- **敌弹可以被打掉**，所以火力密度同时是攻击力和防御力。连消越多，分数和音高一起往上爬。
- 每章第一关（第 1、5、9、13 关）开打前可以挑机翼；关卡中途换翼只能靠打掉运载火箭捡菱形道具。
- 第 4n+2 关（第 2、6、10、14 关）有跳关门，撞进去省 4 关——但跳过去的 Boss 一点没削弱。

## 进化：同型号叠加升阶

捡到**和手上同型号**的机翼就升一阶：Mk.I → Mk.II → Mk.III，冷却更短、每发更重，
带铁球的机翼到顶阶还会多挂一枚。三条约束让进化不至于毁掉别的设计：

- 阶级只乘伤害，不碰 `pierce`／`ground`／横向速度——所以**进化不能把选错的机翼变成对的**
  （`wings.test.js` 逐阶验证正确答案的优势倍率一模一样）。
- 阶级**跟着机翼走，不跟着人走**：弃翼时脱落的道具带着阶级一起飞出去，接回来还是 Mk.III，
  飘走就白攒了。攒得越高，那一下弃翼就越贵。
- 换成别的型号是从 Mk.I 重来；掉命复活也只还原成这一关带进来的那只 Mk.I。

于是运载火箭掉重复机翼不再是「又一个一样的」，而是一次值得冒险去接的升阶机会。

## 十种常规机翼

冷却越短火力越密，而火力密度决定你能不能把弹幕压下去。

- `C` 加农炮：两路高速直射，射速最快，通用首选。
- `W` 宽幅炮：5 路扇形，横向覆盖最广。
- `M` 排炮：3 路平行，走位不用太精细。
- `V` 防卫炮：正面 180° 弹幕，射程极短，专打贴脸的子弹。
- `S` 三向炮：正前加左右，打侧面弱点的唯一趁手工具。
- `A` 前后炮：应付从后方绕上来的敌机。
- `H` 铁球炮：两路直射加两枚绕机自转的铁球，攻守兼备。
- `J` 穿甲弹：射速很慢，但能穿透装甲打到壳里的核。
- `F` 火焰炮：短射程，一发连穿几个目标。
- `D` 对地机翼：两枚落向低空的炸弹，贴地的堡垒只吃这一种。

还有一种秘密机翼 `SS`（四向穿甲加两枚铁球），只在后期关卡的运载火箭里出现，选单上没有它。

## 五种实验机翼（第 9 关起解锁）

它们**不是更强的常规机翼**：四种弱点的答案仍然只在常规十种里，拿实验机翼啃装甲反而更慢。
它们强在另一根轴上——吃弹幕、扫编队、铺覆盖。这游戏一半的压力来自敌弹，
所以「把弹幕吃掉」本身就是一种解法。

- `G` 引力井：射出一口缓慢的引力井，把射程内的敌弹**拽进井心湮灭**。正面强行开路。
- `Z` 链弧炮：命中后电弧跳到旁边的敌人身上，编队越密一发打掉的越多。
- `L` 相位激光：极高射速的细束光，一发连穿整列敌人，但完全没有横向覆盖。
- `X` 反物质弹：一发慢速重弹，命中或耗尽时炸成一圈碎片，碎片同样能消弹。
- `Q` 量子分身：在场地另一侧投出一具**镜像分身**同步开火，一个人管两条线。

## 弱点：武器即钥匙

每个 Boss 是一道题，题面是弱点类型，答案是某一种常规机翼。**选错不是慢一点，是把一场仗拖成一场消耗**——
装甲会挡掉八成伤害。这不是数值失衡，是设计：

- `core` 壳内正中：只有穿甲弹（`J`/`SS`）打得进去。
- `side` 两侧炮座：要飞到和 Boss 齐平的高度，从侧面把火力送进去（`S`/`W`）。
- `low` 贴地：平射会从它头上飞过去，得用炸弹（`D`）。
- `swarm` 生物体：没有装甲，哪儿都能打穿，难的是它泼出来的弹幕（火力密度最高的 `C` 最稳）。

Boss 血量不是手填的：`levels.js` 用「推荐机翼的有效 DPS × 目标时长 × 实测折扣」反推出来，
所以「带对了打十几秒」这句话由算式保证。实测（同一个机器人、同样不死条件、都不捡场上的机翼）：
第 3 关 8.1s / 14.3s，第 7 关 14.1s / 47.1s，第 8 关 10.3s / 32.5s——后面那个数字是硬啃的代价。

场上的菱形道具会直接告诉你它打不打得进本关弱点：**能打进的描一圈金边，不能的整枚压暗**。
否则「捡到手才发现是把螺丝刀」就成了运气问题。

## 反馈

这游戏有两组声音必须一听就分得开，因为它们对应完全不同的处境：

- **`pierce` 与 `chip`**：打进弱点是亮的上滑音，被装甲挡住是又钝又闷的一下。
  选错机翼的惩罚以前只写在数值里，现在耳朵直接告诉你「这只翅膀不对」。
- **`pop` 与 `hit`**：打掉一发敌弹比打中一个敌人更亮，因为一个是防守成功，一个是进攻生效。
  消弹音高跟着连消数爬大调音阶（0、2、4、5、7、9、11、12 半音），第八发封顶。

- 进化是一串四级往上顶的琶音加一层亮噪，压过接翼和换翼：同一帧里最该被听见的是「上了一个台阶」。
  满阶再捡到同型号会给一声轻应答，不静默、也不抢戏。
- 主动弃翼和被打掉翅膀是两种声音：一个是决定（下沉滑音），一个是事故（更硬、更难听，还会震）。
- 无敌结束而新翼还没接上时，会响两声催命的裸机警告——那是全局最危险的一瞬。
- 掉命、打掉 Boss、跳关门各自独占一拍，消弹和爆炸不许盖在上面。链弧的跳弹声压得极轻，
  因为它一帧可能响好几次。
- 震动只给关口事件（弃翼、掉翼、裸机、进化、掉命、跳关、Boss 阵亡、通关、失败），消弹和打中一概不震。
- 右下角可以随时静音，选择记在本地；静音状态下不会建出音频线程。
- 音效全部由 WebAudio 现场合成，不引任何音频文件；`prefers-reduced-motion` 下庆祝动画自动关掉。

## 机身特效

全部在 `render.js` 里，只读模拟状态，画错也影响不到判定。每一项都对应一条玩家需要知道的事：

- **相位残影**：只在下潜（弃翼换来的那 1 秒）时拖出一串半透明机身——这一串本身就是「现在打不到我」。
- **护盾环**：挨打换来的无敌是白环，弃翼换来的下潜是蓝环，两种无敌看得出区别；机身闪烁而环常亮，
  所以还剩多久一眼看得出。
- **阶级辉光**：Mk.II 以上给翼尖描一层随阶级变亮的光，翼下刻着 I / II / III。脱手飞出去的机翼
  也标着阶级——它值不值得追回来全看这个。
- **裸机警示**：没翼的时候画面四边泛起一层会呼吸的红。这是再挨一下就掉命的状态，值得一个躲不开的提示。
- **量子分身**：镜像那一侧真的画着一具半透明机身，它的子弹也画得更淡。
- **引力井**：一圈会转的吸积环，半径就是真实的作用范围；被拽进去的敌弹当场炸成火花。
- **链弧**：两点之间抖几下的折线，只活六帧。
- **进化闪光**：一次短促的白光加一圈火花，0.26 秒就退干净——够醒目，但不挡视线。

## 结构

`src/game/` 是纯逻辑层，不碰 DOM：`rules.js` 定义场地、速度和计分，`wings.js` 是十五种机翼的火力
配置、三阶进化和那套弱点倍率，`levels.js` 是 16 关的波次与 Boss（血量由算式反推），`enemies.js` 管敌人和
敌弹的行为，`boss.js` 管 Boss 走位与弱点位置，`simulation.js` 是固定步长的状态机，
`input.js` 把拖动、轻点和键盘归一成同一份输入，`random.js` 提供确定性随机。

`src/scene/` 是表现层，不写回模拟状态：`render.js` 用 Canvas 2D 画星野、敌人、弱点标记、机身特效和粒子；
`readout.js` 派生 HUD 文案（中文全在这一份里）；`audio.js` 派生音效并现场合成。

`audio.js` 和表现层同一套分工：`soundsFor` / `vibrationFor` 是从 effects 派生的纯函数，能单测；
只有 `createAudio` 碰 `AudioContext`，而且懒建——静音开局一个音频节点都不建。
`over` 和 `won` 是状态跳转而不是 effect，这两声由 `App.jsx` 在状态变化时补。

这条边界让确定性回放成立：同一关加同一串输入，模拟结果逐字段一致，测试因此不需要浏览器。
`test/playthrough.test.js` 用 `test/bot.js` 里那个「会躲、会捡翅膀、会按弱点站位」的机器人跑完
16 关，守住三件事：每一关带对机翼都过得去、Boss 战时长落在设计区间、以及**拿错机翼真的会被惩罚**。
那个机器人还会**挑着捡**：不值得的机翼道具它会绕开，因为撞上去等于把手上的钥匙换成一把螺丝刀。
