# 《糖怪吞噬》游戏设计与实施规划

## 名称约定

本文档同时出现两个名字，含义不同，不可混用：

- **霓界吞噬**：项目基线名，对应目录 `nijie-tunshi`、`README.md` 和全部机制层命名。指质量、能力、点火、宇宙循环等与皮肤无关的规则。
- **糖怪吞噬**：当前实施的“怪物糖果”皮肤标题，对应玩家实际看到的配色、材质、标签与叙事文案。

历史章节中的天体术语（星尘核、原恒星、恒星点火）与糖果术语（糖心幼体、熔糖巨怪、糖化爆发）指同一套状态机，映射见“阶段命名映射”。

## 产品定位

《糖怪吞噬》是一款 3D 滚动吞噬闯关游戏。玩家操控持续滚动的发光糖心，在由 AI 编排、程序生成器构建的怪物糖果世界中吞噬质量不超过自身能力的果冻怪、棒棒糖桩、软糖块、夹心角兽和糖晶簇，逐步增大体积并完成关卡目标。

参考《Hole.io》的成长反馈和短局节奏，但不复刻黑洞、城市或平面吞噬表现。游戏的辨识度来自真实糖心滚动、立体糖果道路、几何糖壳瓦解、霓虹糖釉材质和规则会变化的程序化糖域。

## 怪物糖果视觉方向

当前实施采用“怪物糖果”世界观包装：玩家是一颗会滚动的活体糖心，吞噬彩色糖果怪与几何甜点来长大；三环是糖果光环，卫星是随行糖宠，恒星点火是核心完全糖化后的霓虹爆发。该方向只改变名称、配色、材质、粒子、标签、HUD 和叙事文案，不改变质量、能力、点火、宇宙循环或确定性模拟规则。

视觉目标是高饱和但层次分明：深焦糖/薄荷夜空背景，玩家核心为发光果冻质感，糖环使用透明釉面渐变，目标怪物使用糖果条纹、眼球式高光和反方向粒子流，核心与裂隙呈现糖果熔炉到彩虹糖洞的变化。

### 体素风格

游戏采用体素（voxel）美术风格：所有实体由离散方块单元构成，不使用平滑曲面。这是渲染层的硬约束，模拟层的连续坐标与半径不变。

- 玩家糖心、糖果怪、糖板和锚点都以方块簇建模。球体感通过多层递进的方块外壳表达，而不是高分段球面。
- 方块单元使用统一网格尺寸，物体尺寸按单元数取整；`size` 字段决定占用的单元数而不是连续缩放值。
- 体素风格与高度障碍天然契合：障碍高度以整数单元表示，玩家的通行高度直接读作“能越过几层方块”，无需额外的高度标注隐喻。
- 材质保持糖果配色与 HDR 自发光，但取消各向异性高光；糖釉质感由方块面的亮度分层和边缘描线表达。
- 体素化让重复几何天然适合 InstancedMesh：同一单元网格 + 不同变换矩阵，这直接服务于性能预算。

#### 体素网格生成

`src/scene/voxel.js` 是不依赖 three 的纯函数体素化器，便于单元测试：

- `voxelOccupancy(shape, resolution)` 在归一化坐标 `[-1, 1]³` 上按单元中心采样五种隐式形状：`sphere`、`box`、`cylinder`、`prism`、`octahedron`。
- `voxelSurface(shape, resolution)` 只输出暴露面，内部面全部剔除，返回 `positions` / `normals` / `uvs` / `colors` 平铺数组。实心立方体在分辨率 N 下恰好产生 `6N²` 个面，这是剔除正确性的判据。
- 法线一律是单位轴向，UV 按面局部展开。
- 顶点色烘焙面亮度分层：顶面 1.0、侧面 0.88 与 0.80（区分左右与前后）、底面 0.58，再叠加逐单元 ±4% 的确定性微差打散大面积同色。没有这层分层，一整块糖会糊成单色剪影。微差用 `Math.sin` 哈希而非随机数，保证同一形状逐字节可复现。
- 几何按“形状 + 分辨率”缓存一次，实际尺寸交给 `mesh.scale`，20 个关卡对象共用 5 份网格。
- 只有体素网格带 `color` 属性，因此材质分两支：`voxelGlowMaterial` 开启 `vertexColors` 与 `flatShading`，平滑几何继续用 `glowMaterial`。

各糖果类型的分辨率与半轴缩放集中在 `VOXEL_PROFILES`，从原平滑几何的等效体积换算：果冻怪与棒棒糖桩 8、软糖块 5、夹心角兽 8、糖晶簇 9、糖心熔炉 11、玩家糖心 12。单个对象的三角形数在 300 到 732 之间。

#### 保留平滑的部分

体素化只作用于实体，能量场保持平滑，否则可读性下降：

- 三条糖釉环、浑天仪、彩虹糖洞通道与出口光柱使用 Torus / Ring / Cylinder，由渐变着色器驱动，不体素化。
- 糖宠光晕（halo）保持球面加色混合；糖宠本体已体素化。
- 吞噬碎裂的碎片保持四面体：尺寸只有 0.02 到 0.1 单位，方块与四面体在该尺度无法区分，而四面体更像碎裂的糖壳。

### 尺寸口径决策

三个半径口径必须区分，不可互相替代：

- **视觉半径 = 吞噬半径 = `radiusForMass(mass)`**（未截断）。玩家看到的体积就是能吞到的范围，这是有意设计，不是缺陷。
- **导航半径 = `min(radius, 2.35)`**（截断）。用于墙体碰撞、结构阻挡和边界钳制。
- 两者在质量约 8.5 以上开始分离，质量 130 时为 5.46 与 2.35。

导航半径的截断是缺失高度系统的临时替代：真正的规则应该是“体积足够大时直接从矮墙上滚过”，而不是“大球用小碰撞体挤过墙缝”。高度跨越落地后应移除或大幅放宽该截断，见“实现状态”。

### HDR 糖果光照

- 场景使用深粉紫环境底光、薄荷轮廓光和暖金主光构成三点照明；背景保持低亮度，玩家、糖釉环和当前目标优先进入高亮层次。
- 玩家糖心使用 HDR 自发光与低粗糙度高光；成长阶段只改变核心色温、外壳透明度、拖尾密度和发光强度，不增加第二套判定。
- 糖果怪使用眼球式高光点和薄糖霜轮廓，暗极性目标以紫外糖霜向外喷发，甜极性目标以暖金糖屑向内回收。
- 糖化爆发时短暂提高曝光和点光强度，彩虹糖洞从暖金过渡到薄荷白；离开爆发状态后曝光回落，避免长期画面过曝。
- 光照预算固定：一个半球光、一个阴影主光、两个补光和玩家跟随点光，不随对象数量增加灯光；移动端不启用额外后处理。

灯光在 `src/scene/createScene.js` 中一次性创建，共五盏；强度由 `src/game/lighting.js` 按质量与状态推导，渲染层只做插值：

- 半球光 2.2 固定；主光（带 1024×1024 阴影）4.0 到 4.55；轮廓光 2.3 到 3.7；补光 1.35，牵引时升到 1.8。
- 玩家跟随点光 1.5 到 4.8，照射距离 9 到 14，颜色随质量从暖白经粉红过渡，点火后切为亮金。
- 曝光 1.08 到 1.58，由质量占比、糖化爆发和当前能力共同抬升；爆发结束后回落，避免长期过曝。
- 所有动态量以 `质量 / 130` 归一化，因此光照强度与成长阶段严格同步，不需要单独的阶段光照表。

### 糖果怪活物行为

- 普通糖果怪是活物但不攻击玩家：当玩家明显可吞噬它时，它会向远离玩家的方向缓慢滚动；当糖果怪明显大于玩家时，它会缓慢靠近并压缩路线空间。
- 行为只在 14 米感知半径内启用。逃离速度 1.45，逼近速度 0.72，位移再乘以紧迫系数 `0.45 + (1 - 距离 / 14)`，即 0.45 到 1.45 倍；速度阻尼每步 0.88。玩家最大速度为 11，因此糖果怪始终追不上也逃不掉。
- 逼近条件是目标质量大于玩家质量的 1.8 倍，与吞噬资格之间留出中间带，避免玩家刚好卡在阈值上时糖果怪来回抖动。
- 重力碎片（带 `gravity` 标记）、糖心熔炉和已解锁核心不参与自主移动，避免破坏教程和最终点火窗口。
- 躲避或逼近不会改变质量、燃料、极性、吞噬资格和回放输入契约；同一 seed 与输入仍保持确定结果。
- 自动回放在第一宇宙和后续宇宙都必须完成糖化爆发；行为只要求玩家持续追击，不允许制造死锁。
- 当前糖果怪与被牵引碎片的位移都会做 `LEVEL.bounds` 钳制，并对墙体和未破坏的结构做包围盒推出，因此不会穿墙或跑出场地。推出使用对象 `size` 的一半作为半径，与玩家的导航半径口径独立。

### 糖果怪情绪可读性

`src/game/moods.js` 定义六种情绪，按固定优先级取第一个命中项：休眠 → 酸味 → 引力锁定 → 躲避 → 逼近 → 观察。优先级不可调换，否则暗极性目标会被误读成可吞噬。

- 休眠（`dormant`）：已被吞噬的对象或未解锁的糖心熔炉，无倾斜、无起伏，高光保持基准值。
- 酸味（`sour`）：暗极性目标叠加紫外十字糖霜，轻微后缩，高光在基准值上做较强脉动，提示不可吞噬且会排斥玩家。甜极性目标叠加暖金圆点糖霜。
- 引力锁定（`drawn`）：被糖引力作用的糖果怪做短促摆动，起伏幅度最大，不改变位移规则，只提供可读的反馈。
- 躲避（`fleeing`）：可吞噬的糖果怪在靠近玩家时身体轻微后缩，白色糖霜高光缩小，标签颜色保持可吞噬暖色。
- 逼近（`looming`）：质量超过玩家 1.8 倍的糖果怪身体轻微前倾，眼睛高光放大，提示玩家需要绕行或先吃小目标。
- 观察（`watching`）：以上都不命中时的兜底状态，姿态中性，用于“暂时吃不掉但也不威胁”的目标。

倾斜与起伏的幅度都乘以 `1 - 距离 / 14`，因此远处糖果怪表现平静，玩家靠近时情绪才明显。所有情绪表现由权威模拟状态推导，不允许场景层自行决定吞噬资格。

## 跨宇宙主线

《霓界吞噬》的长期主线不是让同一个球无限增大，而是让玩家在每个宇宙中完成一次完整的天体演化：

```text
星尘核 -> 小行星 -> 原行星 -> 行星 -> 原恒星 -> 恒星点火
       -> 宇宙裂隙 -> 下一个宇宙 -> 新规则下重新演化
```

每个宇宙是一轮独立关卡。玩家进入新宇宙后重置局内质量、可吞噬实体、锚点、行星环充能、卫星推进位置、共鸣资源和技能冷却，但保留宇宙层级、累计星级、已发现的宇宙规则和外观解锁。

### 玩家成长阶段

| 阶段 | 皮肤名 | 质量区间 | 玩家感受 | 新能力或主目标 |
| --- | --- | ---: | --- | --- |
| 星尘核 | 糖心幼体 | 0–12 | 弱小、灵活，第一次形成稳定核心 | 冲刺、吞噬尘埃和微型碎片 |
| 小行星 | 果冻怪 | 12–32 | 开始拥有可读的局部引力 | 中环与引力牵引，捕获小型碎片 |
| 原行星 | 糖霜兽 | 32–60 | 可以突破原先无法通过的区域 | 外环与相位穿越，撞碎大型岩层 |
| 行星 | 硬糖王 | 60–90 | 建立三环三卫星的完整天体系统 | 选择稳定或高风险燃料路线 |
| 原恒星 | 熔糖巨怪 | 90–130 | 质量足够但核心尚未点火 | 收集氢氦燃料、解除三轴点火锚点 |
| 恒星 | 霓虹糖星 | 130+ 且已点火 | 核聚变启动，照亮整个星域 | 释放恒星风并打开宇宙裂隙 |

阶段由 `src/game/progression.js` 的 `PLAYER_STAGES` 定义，皮肤名是权威字符串，天体名仅用于文档叙述。最后一阶段带 `requiresIgnition`，质量到 130 但未点火时玩家仍停留在熔糖巨怪。

### 阶段命名映射

三套历史术语指同一状态机，写代码和文案时按此表对齐：

- 质量 0 / 星尘核 / 糖心幼体 / 视觉“初醒” / 遭遇阶段 `awakening`
- 质量 12 / 小行星 / 果冻怪 / 视觉“虹彩” / 遭遇阶段 `gravity`
- 质量 22 / 无对应成长阶段 / 无皮肤名 / 无视觉阶段 / 遭遇阶段 `crossroads`（仅用于分岔路提示）
- 质量 32 / 原行星 / 糖霜兽 / 视觉“脉冲” / 遭遇阶段 `phase`
- 质量 60 / 行星 / 硬糖王 / 视觉“星冠” / 遭遇阶段 `core`
- 质量 90 / 原恒星 / 熔糖巨怪 / 视觉“高维” / 遭遇阶段 `protostar`
- 质量 130 / 恒星 / 霓虹糖星 / 糖化爆发 / 遭遇阶段 `ignition`

`crossroads` 只存在于 `src/game/encounters.js` 的遭遇阶段列表，不生成新环、新卫星或新能力。

质量 90 不再直接通关，只代表三条行星环充满并进入原恒星阶段。玩家必须完成燃料和点火目标，才会真正成为恒星。

### 三类进度

游戏明确区分三类进度，HUD、关卡验证和视觉表现不得互相替代：

1. **质量**：决定天体阶段、尺寸、吞噬能力和可进入区域。
2. **行星环充能**：三颗卫星分别位于三条环的充能前沿；卫星绕对应环一圈表示该环充满。卫星后方喷出稀疏的几何能量粒子，连续能量弧负责显示精确进度。
3. **恒星点火**：由燃料比例、核心稳定度和点火锚点共同决定。质量足够但条件未满足时，玩家仍是原恒星，不能进入下一宇宙。

### 第一宇宙：初生星海

第一宇宙使用固定 seed `482193`，作为所有主机制的教学关：

1. **星尘带**：出生点前方提供第一颗光球和可冲刺晶板，玩家在数秒内开始吞噬；第一颗卫星从环起点推进。
2. **小行星海**：质量 12 解锁引力牵引。稳定路线资源分散，碎星风暴路线资源密集但碰撞风险更高。
3. **原行星熔炉**：质量 32 解锁相位，玩家穿越电磁门并回收重元素核心。
4. **行星系统**：三条行星环逐步完成，玩家选择氢氦燃料和高质量矿物，既要提高质量也要保证点火燃料比例。
5. **原恒星点火**：质量 90 后开放三轴点火区。冲刺破除外壳锚点，引力向核心输送燃料，相位穿越辐射环启动点火节点。
6. **恒星诞生**：质量、燃料、稳定度与锚点同时满足后启动核聚变；玩家释放恒星风，照亮星域并打开宇宙裂隙。
7. **宇宙跃迁**：三条环展开为浑天仪，恒星压缩成跃迁核心，穿越裂隙进入下一宇宙。

### 恒星点火条件

第一版使用确定性、可测试的点火条件。权威实现是 `src/game/rules.js` 的 `stellarIgnitionReady`，共六项，全部满足才点火：

```text
质量 >= 130                 (STELLAR_IGNITION_MASS)
氢氦燃料 >= 100             (STELLAR_FUEL_TARGET，上限即目标值)
核心稳定度 >= 75            (STELLAR_STABILITY_TARGET)
三个点火锚点全部解除        (north / south / phase 的 integrity <= 0)
相位点火节点已激活          (encounter.phaseIgnited)
恒星核心已吞噬              (core 对象 active === false)
```

锚点与能力严格一对一，用错能力不产生伤害：

- `north` 锚点只吃冲刺，命中即造成 2 点，一次解除。
- `south` 锚点只吃引力牵引，按 `dt * 1.8` 持续削弱，约需 1.11 秒不断牵引。牵引额外获得 3 米作用距离加成。
- `phase` 锚点只吃相位穿越，命中即解除，并同时置位 `phaseIgnited`。

`north` 与 `south` 同时归零后核心才解锁（`coreUnlocked`）。核心解锁后不再校验玩家质量，可以直接吞噬。锚点状态只保存在 `state.anchors` 一处，`coreUnlocked` 与点火判定都从它派生，不存在第二份记账。

燃料只来自带 `fuel` 字段的对象，累加后按 100 截断。第一关燃料总量为 160（`prism-1` 18、`cube-2` 14、`prism-2` 16、`crystal-1` 24、`crystal-2` 28、`prism-3` 30、`core` 30），需求 100。燃料分散在迅捷与稳健两条路线上，漏掉任意单个来源都不会导致无法点火，但收集顺序会影响用时评价。

吞噬普通几何体增加质量；吞噬带 `fuel` 标签的天体同时增加恒星燃料。点火失败不会清空整局，只将玩家弹回原恒星阶段并保留三条完整行星环，让玩家重新补充燃料和稳定度。

#### 核心稳定度

稳定度从 100 起算，点火要求不低于 75，即整局只有 25 点容错。它是唯一会因玩家操作失误而倒退的资源：

```text
过载吞噬：质量 >= 12 后吞下比自身更重的目标      -6
高速撞击：非冲刺非相位状态下以速度 > 9 撞墙       -1.5
惩罚冷却：0.6 秒内不重复扣减
恢复延迟：最后一次扣减后 1.5 秒开始回升
恢复速率：+1.2 /秒，上限 100
```

过载吞噬直接和“过载余量”机制耦合：余量让玩家总能吃掉略大于自己的目标，稳定度则给这个便利标了价。急于变大就要付稳定度，先吃小目标垫质量则免费。质量 12 以下属于教学阶段，不计过载惩罚，避免开局连吃三颗糖球就被扣光。

高速撞击只惩罚“无意义的莽撞”：冲刺和相位撞墙是设计内的正当操作（用于破糖板、穿糖雾门），不扣稳定度；普通滚动最大速度为 11，因此扣减窗口只有 9 到 11 这一段。

扣减会推送 `stabilityLoss` 动作事件，带 `cause`（`overload` 或 `impact`）与扣减量，供 HUD 与特效层消费。

### 下一宇宙循环

恒星点火后的跃迁不是结算终点，而是下一轮的入口。循环状态至少包含：

```javascript
{
  universeIndex: 1,
  universeId: 'genesis',
  cumulativeStars: 0,
  discoveredRules: [],
  runResult: null
}
```

进入下一宇宙时：

- `universeIndex += 1`，切换关卡配方和宇宙规则。
- 玩家回到星尘核，质量归零，重新建立三环和三卫星。
- 保留累计星级、最佳连击、已完成路线和宇宙发现。
- 新宇宙改变空间规则，而不是只提高数值：反物质宇宙强调正负质量，双星宇宙强调共同轨道，暗物质宇宙强调引力感知，衰亡宇宙强调燃料流失。
- 第一版第二宇宙先复用固定地图几何，并改变配色、对象质量倍率、燃料密度和规则提示；后续再替换为独立 AI 配方。

#### 宇宙表

`src/game/universes.js` 定义四个宇宙，按 `universeIndex` 取模循环，每循环一轮全局质量倍率再加 0.04：

| 序号 | id | 名称 | 规则 | 质量倍率 | 已实现的机制差异 |
| ---: | --- | --- | --- | ---: | --- |
| 1 | `genesis` | 软糖幼巢 | 稳定糖引力 | 1.00 | 基线，无额外规则 |
| 2 | `antimatter` | 酸味反物质潮 | 甜酸极性 | 1.04 | `prism-1`、`crystal-2`、`core` 带暗极性，需牵引反转 |
| 3 | `binary` | 双糖摇篮 | 双核共糖化 | 1.08 | 仅倍率与文案，双核轨道未实现 |
| 4 | `dark-matter` | 黑糖深空 | 糖引力感知 | 1.12 | 仅倍率与文案，牵引显形未实现 |

质量倍率作用于关卡对象的 `mass`，不改变点火阈值。因此高倍率宇宙实际上更容易堆到 130，但暗极性和锚点顺序构成真正的难度来源。U3 与 U4 目前只是换色与倍率关卡，机制实现见“实现状态”。

#### U2 · 反物质潮：极性质量

- U2 的燃料天体按固定配方带有亮极性或暗极性；普通成长目标保持中性，确保开局吞噬链不会死锁。
- 亮极性燃料可直接吞噬，暗极性燃料会排斥玩家并阻止吞噬。
- 质量达到 12 解锁引力后，玩家在牵引范围内持续作用于暗极性燃料即可将其反转为亮极性；反转结果在本局内保持稳定。
- 暗极性使用冷紫红外壳和反向粒子流，亮极性使用暖金外壳和向内粒子流；近距离目标标签同时显示质量与极性符号。
- 自动回放和手动路线都必须能在不重置关卡的情况下反转所需燃料、完成恒星点火并进入 U2 裂隙。

### 关卡评价

星级由 `src/game/rules.js` 的 `resultStars` 判定，五个维度全部参与运算：

```text
三星：用时 <= 150 秒 且 最高连击 >= 6 且 用过相位捷径 且 全程零失稳
二星：用时 <= 195 秒 或 最高连击 >= 4 或 燃料纯度 >= 80%
一星：完成糖化爆发并穿越裂隙（其余情况）
```

三星要求四项同时成立，缺任何一项都掉到二星——包括只掉过一点稳定度。二星给出三条独立路径，让擅长速度、连击或路线精度的玩家各有台阶。

**燃料纯度**衡量路线精度：燃料在 100 处截断而全关有 160，多吃的部分是浪费。纯度 = 实际计入的燃料 / 吃下去的燃料总量，只吃够用的就接近 1。

**零失稳**是"这一局打得干净"最直接的证据：稳定度是唯一会因操作失误倒退的资源，全程未跌破满值意味着既没有过载抢吃、也没有莽撞撞墙。

参考回放路线实测拿二星：用时 39 秒、纯度 94%、零失稳，但最高连击只有 5 且从未穿过相位门。三星需要玩家主动绕去糖雾门并把连击串到 6，这个差距是有意的。

结算面板显示用时、最高连击、燃料纯度、最低稳定度、累计星级与下一宇宙；结算数据额外记录吞噬数、路线类型与点火尝试次数。

## 核心循环

1. 在出生区吞噬光点和小型球体。
2. 体型增长后进入新的道路或吞噬更高质量的几何体。
3. 激活能量门、组合机关和地图核心。
4. 达到关卡要求后进入共鸣出口。
5. 按用时、吞噬率、连击和探索率获得评价。

单局目标时长为 3 至 6 分钟，成长阶段依次为小型物件、建筑级几何体、地形结构和地图核心。地图应提前展示暂时无法吞噬的大型目标，使成长边界始终可见。

## 策略玩法

霓界吞噬的核心是策略而非单纯滚动。先后顺序决定了能否通关，玩家需要像设计路线一样选择吞噬顺序。

### 迷宫路线与吞噬顺序

每张地图本质上是一座具有成长状态的立体迷宫。房间、回廊、坡道、窄门和高低障碍组成路线图，玩家必须根据当前质量、体型高度、阶段充能和未探索区域安排吞噬顺序。

- 每张地图存在多条可行路线，但每条路线都有一个"最优先后顺序"。先吞低质量物体解锁通道，再回头处理高质量目标。
- 关键过道由大型几何体或窄门构成，标注该过道所需的最小质量门槛。玩家在体型不足时只能记下编号，等成长后再返回。
- 体型增长不可逆。一旦超过某个过道的通过上限，该过道将永久关闭，玩家无法原路返回。这迫使玩家在变大前想清楚是否还需要回到该区域拾取资源或捷径。
- 地图设计保证至少一条"只变大不回头"的通关路线，但三星路线通常需要玩家在体型尚小时先穿过窄门拾取隐藏资源，再变大绕行主路。
- 同一房间内的物体不应全部无脑吞噬。某个高质量物体可能让阶段充能立即满格，导致球体变大、引力范围扩大，并使原本可通过的窄道关闭。
- 迷宫通过可观察规则而不是隐藏陷阱制造难度。玩家在做决定前，必须能看到门槛数字、障碍高度、可能获得的质量以及充能后果。

### 高度障碍

路面障碍物具有不同高度，球体的当前体型同时对应一个可跨越高度。玩家明显高于障碍物时，可以从障碍上方滚过或将其压入地面形成道路。

```text
允许跨越：玩家通行高度 >= 障碍高度 + 安全余量
允许推开：玩家质量 >= 障碍推力门槛
允许穿过窄道：玩家质量 <= 过道质量上限
```

- 低矮台阶用于提示成长收益：初始阶段需要绕行，成长后可以直接跨越。
- 中等障碍可能一侧较低、一侧较高，形成有方向性的单向路线。
- 高墙始终不可直接跨越，只能通过机关、吞噬支撑结构或寻找迷宫通道解决。
- 障碍上显示高度数字，例如 `H 2.4`；玩家 HUD 同时显示当前通行高度。足够跨越时数字变为阶段色，不足时保持暗灰。
- 高度跨越与窄道上限形成互斥选择：过早成长可以越过矮墙，却可能失去进入窄道收集隐藏资源的机会。
- 自动验证必须按阶段检查所有关键房间，确保玩家不会因错误吞噬顺序进入无解状态；允许形成低评价路线，但主流程至少保留一个可恢复或可重开的解法。

#### 跨越与窄门规则

权威实现在 `src/game/rules.js`，模拟层据此决定是否发生碰撞：

```text
通行高度 = 1.15 + sqrt(质量 / 7)          （与视觉半径同一公式）
允许跨越 = 通行高度 >= 障碍高度 + 0.6      （CROSS_SAFE_MARGIN）
允许穿过窄门 = 窄门 minMass <= 质量 <= 窄门 maxMass
```

安全余量 0.6 让"再吃一个就能翻过去"有明确门槛，而不是贴着相等值来回抖动。`massToCross(height)` 反解出恰好能跨越所需的质量，供关卡标注与验证器使用。

第一关的高度阶梯刻意对齐成长阶段阈值：

- `wall-a` 高 1.9，需质量 12.8（对应果冻怪 12）
- `wall-b` 高 2.7，需质量 32.4（对应糖霜兽 32）
- `wall-d` 高 3.5，需质量 60.9（对应硬糖王 60）
- `wall-c` 高 6.0 且带 `unclimbable` 标记，任何质量都不可跨越

标记是必需的，不能只靠高度数值：质量没有上限，玩家吃到足够大时通行高度会超过任何有限高度。`wall-c` 曾只靠 6.0 的高度表达"永久高墙"，但质量 208 以上就能翻过去，而回放本身就能到 177、贪心见证能到 253。文档描述的"高墙始终不可直接跨越，只能通过机关或迷宫通道解决"必须由显式标记承载。

窄门是双侧约束。上限承载"成长不可逆"——体型越大越过不去；下限承载"这条捷径要先长到一定程度才推得开"。两者组合出真正的顺序谜题：有的门要趁小穿过，有的门要先长大才能推开，而两个窗口未必重叠。

- `gate-north` 上限 18，位于出生区通往中段的捷径上
- `gate-mid` 上限 45，位于锚点区西侧
- `gate-core` 区间 12–60，贯穿南侧高墙。质量不足 12 推不开，超过 60 挤不过去，是一段有限时窗的捷径

窄门开口宽度必须大于两倍导航半径，否则膨胀本身就把通道封死。`gate-core` 宽 5.5，而质量区间上界对应的导航半径被截断在 2.35，刚好留出余量。为给它让出位置，原先横跨 11 单位的 `wall-c` 拆成了 `wall-c` 与 `wall-c-east` 两段，两段都保留 `unclimbable`。

矮墙一旦可以跨越，也不再遮挡糖引力牵引——否则"能翻过去"与"能牵引过去"两套规则会互相矛盾。糖果怪没有玩家的跨越能力，所有墙体与窄门对它们一律有效。

导航半径仍截断在 2.35。跨越规则落地后这条截断的必要性下降，但窄门碰撞仍依赖它，因此暂时保留。

### 数字标注

为支持路线规划，关键物体和过道都带可见数字标签：

- 每个可吞噬几何体头顶悬浮其质量值，例如 `7`、`24`、`52`。玩家一眼就能判断当前能否吞噬以及吞噬后的成长幅度。
- 每条过道、窄门和能量门上方标注通过所需的质量区间，例如 `≤18` 表示体型超过 18 后无法再通过，`≥12` 表示至少需要 12 质量才能推开。
- 数字标签随距离淡入淡出，远处只显示轮廓，靠近时才显示精确数值，避免画面信息过载。
- 当前可吞噬的物体数字高亮为阶段色，暂不可吞噬的显示为暗灰，让玩家在不暂停的情况下快速扫描下一步目标。

### 阶段充能环

成长不再是一旦吞噬就立即跳变，而是引入"充能"过程，强化阶段突破的仪式感：

- 三层共鸣环分别承担三段成长：第一环从质量 0 充能到 12，第二环从 12 充能到 32，第三环从 32 持续充能到 90。质量 60 进入“星冠”配色和能量等级，但不增加第四条环。
- 当前充能环始终是一条完整圆环。未充能部分显示低亮度轨道底色，已充能部分用两种阶段色做连续渐变填充，不通过缺口或半截圆环表达进度。
- 前一条环达到 100% 后才生成下一条完整环；新环以完整低亮度形态整体渐显，然后开始自己的渐变充能。
- 三环全部完整后解锁浑天仪跃迁。跃迁时三环才从共同水平面展开到不同坐标轴，并按不同速度、正反方向旋转，形成测量空间坐标的浑天仪效果。
- 跃迁是不可逆的。一旦进入新阶段，旧阶段的窄门可能就无法再通过，因此玩家在"最后吞噬"前可以观察环的渐变填充判断"再吃一个就会升级"，从而决定是先绕路拾取隐藏资源还是直接升级离开。
- 充能进度对策略至关重要：玩家可以通过刻意避开高质量物体、只吞小物来延缓升级，以便在窄门关闭前收集更多资源；也可以集中吞噬高质量物体快速充能，抢占时间评价。

### 镜头与体型

- 镜头跟随距离与球体半径绑定，并采用非线性拉远曲线：体型较小时拉远幅度小，保持细节和沉浸感；体型较大时拉远幅度增大，避免球体占据过大视野而看不到前路和过道标签。
- 镜头高度同步抬升，使玩家在变大后仍能俯瞰更多过道和数字标注，支持路线决策。
- 进入窄门或复杂地形时，镜头略微拉近并降低跟随灵敏度，防止大幅晃动；离开后恢复默认跟随。

## 操控与镜头

- 桌面使用 WASD 或方向键，移动端使用虚拟摇杆和方向按钮。
- 球体有加速、惯性和阻尼，但转向优先保证响应速度。
- 镜头平滑跟随，并根据球体半径采用非线性拉远曲线（见"策略玩法 · 镜头与体型"），避免大体积球体占据过多视野。
- 可吞噬物体增强发光并显示质量数字标签，不可吞噬物体保持低强度边缘光和暗灰数字。
- 碰到大型结构产生明确阻挡反馈，不让玩家长时间失控。
- 坠落地图后回到最近安全点，并保留当前阶段的成长。

## 吞噬与成长

每个实体拥有独立质量，视觉尺寸只用于表达质量等级。吞噬资格由 `src/game/rules.js` 的 `consumePower` 与 `canConsume` 决定，玩家能力等于自身质量加一个随阶段提升的“过载余量”：

```text
过载余量：质量 >= 60 时为 5，质量 >= 32 时为 3，否则为 2
吞噬能力：玩家质量 + 过载余量
可吞噬：目标 active 且 极性不为 dark 且 目标质量 <= 吞噬能力
糖心熔炉：额外要求 north 与 south 锚点已解除，解锁后不再校验质量
接触判定：水平距离 <= 玩家半径 + 目标 size × 0.72
```

过载余量让玩家总能吃掉略大于自身的目标，是成长不卡死的关键。代价是稳定度：质量 12 以上吞下比自身更重的目标会扣 6 点稳定度，见“核心稳定度”。文档早期提到的“类型阻力”系数并未实现，各类型使用同一判定。

半径与质量的关系为 `半径 = 1.15 + sqrt(质量 / 7)`，质量 130 时约 5.46。碰撞与窄道导航使用被 2.35 截断的半径，吞噬接触与视觉体积使用未截断的真实半径，口径差异与理由见“尺寸口径决策”。

连击窗口为 2.7 秒，倍率为 `1 + min(1.5, (连击数 - 1) × 0.12)`，即最高 2.5 倍。每次吞噬回复 10 点共鸣。

| 类型 | 主要作用 |
| --- | --- |
| 光点、光球 | 初级资源，可连续吸附 |
| 圆柱 | 可以滚动或倒塌，形成道路 |
| 立方体 | 稳定的标准成长资源 |
| 三棱柱 | 构成坡道、障碍和机械结构 |
| 圆环 | 从特定方向穿越或吞噬 |
| 晶体簇 | 高成长收益，通常位于危险区域 |
| 组合结构 | 先瓦解外层，再吞噬核心 |
| 地图核心 | 关卡末期目标，触发出口和世界变化 |

吞噬表现分为吸附、压缩、碎裂和融入四个阶段。大型结构需要渐进瓦解，不应瞬间消失。

### 引力吸附系统

球体成长后形成可视的局部引力场。相对玩家明显较小的悬浮小行星、能量碎片和几何残片会被自动吸附，但完整障碍物、路线机关和接近玩家质量的目标仍必须主动接触或满足机关条件。

当前实现按质量比例判定资格，牵引不是被动光环，必须按住能力键：

```text
牵引资格：目标质量 <= 玩家质量 × 0.18   （GRAVITY_MASS_RATIO）
牵引力度：19 × (1 - 距离 / 7.5)，按 dt 累加到对象速度
速度阻尼：每步 × 0.94
遮挡检测：对象到玩家的线段取 12 个采样点，与阻挡物做 2D AABB 相交
```

比例 0.18 的效果是一条随成长展开的曲线：质量 12 解锁牵引时上限只有 2.2，只能拉动糖屑与最小的两颗果冻怪；质量 60 上限 10.8，覆盖到棒棒糖桩与软糖块；质量 130 上限 23.4，覆盖 15 个对象。糖晶簇、夹心角兽和大质量燃料体要到很晚才拉得动，因此不会在岔路口把玩家推向被迫升级。

- 糖心熔炉永不参与自动吸附。它是关卡主门槛，`canPull` 直接对 `type === 'core'` 返回 false，不依赖比例换算。
- 遮挡物与跨越规则保持一致：跨得过去的矮墙、挤得过去的窄门都不遮挡；跨不过去的墙、关闭的窄门、以及未破坏的糖壳板与糖雾门一律遮挡。
- 牵引半径固定为 7.5，不随阶段或玩家半径变化；视觉上的引力范围表现由外环负责，与判定解耦。
- `massToPull(objectMass)` 反解出恰好能拉动某目标所需的玩家质量，供文档与标注换算。
- 正在被吸附的目标先围绕球体短暂旋转，再进入核心；被吸附轨迹显示其质量数字，玩家仍能理解能量来源。
- 暗极性对象不能被吞噬，且会把玩家推开：在 `导航半径 + size × 0.72` 内产生排斥并把玩家速度衰减到 0.35 倍。在 7.5 米内持续牵引 0.65 秒可将其翻转为亮极性，翻转在本局内不可逆。中断牵引时充能按 `dt * 0.5` 回落。
- `gravity: true` 现在只标记"这是糖屑"：不自主移动、情绪为引力锁定。它不再决定牵引资格。

引力抑制区与随阶段扩大的吸附半径仍未实现。空间分区与每帧吸附上限已落地：牵引、吞噬与糖果怪三处都只遍历玩家邻域，`MAX_PULLS_PER_STEP` 限制单帧最多牵引 12 个对象。

### 行星环与小卫星

玩家行星环的轨道平面、中心和半径在升阶前后保持稳定，避免位置跳变；旋转感来自环上的能量流纹理、发光刻度和沿轨道运行的小卫星，而不是改变整个轨道平面的方向。

- 三条同心环拥有不同颜色和能量等级，内环代表当前可用能量，中环代表阶段充能，外环代表引力范围与高维共鸣。
- 环体保持同心同平面，并各自独立绕球体法线旋转：内环顺时针且较快，中环逆时针，外环顺时针且较慢。升级只改变颜色、可见环数、流光速度和卫星数量，不让圆环被球体自转被动带动。
- 每条环的渐变能量沿自身旋转方向持续流动，并带一个环绕运行的窄高亮波峰，使玩家能直接看出充能方向。圆环充满后使用首尾颜色一致的循环渐变，UV 接缝必须无暗线、缺口或明显色差。
- 小卫星是被核心稳定捕获的能量结晶，不计入可吞噬目标。它们沿固定轨道运行，为引力范围、阶段等级和充能状态提供可读反馈。
- 初醒没有卫星；虹彩出现一颗；脉冲增加至两颗；星冠和高维可出现三颗不同尺寸、不同速度的卫星。
- 卫星不使用随机轨道倾角。所有卫星位于既定同心轨道，必要时只使用很小的高度错层，保证视觉清晰。
- 充能低于 70% 时轨道稳定；达到 70% 后卫星速度和流光亮度缓慢提升；达到 95% 后卫星趋于同相排列，提示即将升阶。
- 升阶瞬间卫星短暂停顿，白紫冲击波扩散，新环/新卫星以渐显方式加入，然后恢复新阶段的稳定轨道速度。

## 关卡机制

主目标类型包括体积突破、核心回收、地图净化、限时冲刺、连锁坍塌和能量运送。普通探索关卡不以倒计时作为唯一失败条件，时间用于星级评价。

- 一星：完成主目标。
- 二星：满足用时或吞噬率要求。
- 三星：完成连击、隐藏区或零坠落目标。

五分钟关卡采用发现、成长、扩张、爆发和收束五段节奏。每个阶段都必须存在从当前体型通向下一等级的资源链。

## 第一关固定路线

第一关“荧光庭院”使用固定 seed `482193`，物体坐标、障碍、质量值和首阶段资源链全部由 `src/game/level.js` 固定定义，不调用 LLM，也不依赖在线服务。

### 关卡数据基线

- 场地边界 `x ∈ [-26, 26]`、`z ∈ [-18, 22]`；出生点 `(-19, 13)`；裂隙出口 `(20, -13)`，半径 2.4。
- 5 面阻挡墙：`wall-a` 1.9、`wall-b` 2.7、`wall-d` 3.5，对应可跨越质量 12.8 / 32.4 / 60.9；`wall-c` 与 `wall-c-east` 高 6.0 且 `unclimbable`，永久不可跨越。可跨越后不再遮挡牵引。
- 3 道窄门：`gate-north` ≤18、`gate-mid` ≤45、`gate-core` 12–60。
- 3 个可交互结构：`crystal-panel` 与 `risk-panel` 为可冲刺破坏，`phase-gate` 为相位可穿。三者均不参与牵引遮挡。
- 3 个点火锚点：`north (10.5, -9.5)` 冲刺、`south (16.8, -9.8)` 牵引、`phase (13.5, -6.5)` 相位。
- 20 个可交互对象，质量从 1 到 52，构成连续成长链：orb 1.2/2/3/4/5 → cylinder 7/9 → cube 10/13/20 → prism 15/18/38 → crystal 24/29 → core 52，外加三块质量 1 的牵引碎片。
- 关卡对象总质量约 261，乘以宇宙倍率后即为该局质量上限；点火需要 130，因此约有一半余量用于容错和路线选择。
- 7 个对象携带燃料，合计 160 点：`prism-1` 18、`cube-2` 14、`prism-2` 16、`crystal-1` 24、`crystal-2` 28、`prism-3` 30、`core` 30。

对象类型对应糖果标签：`orb` 果冻怪、`cylinder` 棒棒糖桩、`cube` 软糖块、`prism` 夹心角兽、`crystal` 糖晶簇、`core` 糖心熔炉。

### 场内动作策略流程

关卡加载后玩家立即获得控制权，不显示静态规划题，也不由自动驾驶替玩家执行路线。策略发生在连续滚动中：玩家观察质量数字、结构符号和远处目标，在维持连击、保留共鸣资源和选择安全/迅捷路线之间取舍。

首关用三条共鸣环依次提供三种实际能力：

```text
内环（开局）  -> 冲刺：锁定短距离方向，撞碎晶板与橙色核心锚点
中环（质量12）-> 牵引：吸附无遮挡的小型碎片，持续削弱青色核心锚点
外环（质量32）-> 相位：穿过紫色能量门，进入高收益捷径
```

质量、吞噬能力和共鸣资源相互独立。吞噬增加质量并恢复少量共鸣；冲刺、牵引和相位消耗共鸣且具有各自冷却。质量 60 与 90 强化现有能力和视觉，不增加第四个操作键。

#### 能力与共鸣经济

`src/game/abilities.js` 的权威数值：

| 能力 | 解锁质量 | 消耗 | 冷却 | 持续 | 速度 | 其他 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 冲刺 dash | 0 | 14 | 1.15 s | 0.24 s | 24 | 破可破坏糖板、解 `north` 锚点 |
| 牵引 gravity | 12 | 16 /秒 | 无 | 按住持续 | — | 半径 7.5、力度 19、锚点加成 3 m |
| 相位 phase | 32 | 28 | 4.5 s | 0.80 s | 16 | 穿相位门、解 `phase` 锚点 |

共鸣池上限 100，起始满值，每秒回复 8 点，每次吞噬额外回复 10 点，钳制在 0 到 100。牵引只要共鸣归零就自动中断，因此持续牵引最长约 6.25 秒。玩家最大移动速度为 11，冲刺与相位在持续时间内覆盖该上限。

固定时间步为 1/60 秒，糖化爆发（`ascending`）持续 4 秒，期间玩家输入停止生效。

首关遭遇按以下节奏展开：

1. 出生廊道将第一颗光球和晶板放在前方，玩家可绕行，也可冲刺直破并延续连击。
2. 达到质量 12 后解锁牵引，散落碎片会沿无遮挡轨迹进入核心，墙体会阻断引力。
3. 中段分为迅捷与稳健路线：迅捷路线距离短、晶板多；稳健路线资源密集、绕行距离长。两条路线均可通关。
4. 达到质量 32 后解锁相位门捷径。错过捷径不会死锁，但影响时间和三星评价。
5. 质量 60 后开始收集恒星燃料；普通几何体主要增加质量，燃料天体同时提高氢氦储量。
6. 质量 90、三环充满后开放原恒星点火区。冲刺和牵引解除已有双锚点，相位节点作为第三个点火条件加入。
7. 质量达到 130，燃料、稳定度、三类点火条件和核心目标全部完成后，玩家成为恒星并打开宇宙裂隙。

星级基于完成时间、最高连击、燃料纯度、点火稳定度和相位捷径：完成恒星点火至少一星；稳定点火或达到时间目标为二星；达到高连击、使用相位捷径且点火零失稳为三星。

首阶段的基础成长链为：

```text
出生点 -> orb-1 -> orb-2 -> orb-4 -> cylinder-1 -> 虹彩阶段
```

产品界面保留“自动演示”按钮，调用 `src/game/replayAgent.js`，通过与玩家相同的移动和能力输入执行固定回放；测试通过 `test/helpers/replayAgent.js` 复用同一代理，验证无网络、无 API key、无 LLM 时仍能稳定完成成长、点火和宇宙跃迁。自动演示是可随时停止的验证与展示工具，不参与玩家评价。

第一关必须满足：相同 seed、相同输入和相同时间步产生相同结果；后续 AI 只输出新地图的结构化配方，不能接管即时驾驶、碰撞、能力、点火或升级判定。

### 浑天仪跃迁与外部环阵

关卡出口包含两层环结构：玩家身上的三层共鸣环组成浑天仪，场景中的外部同轴圆环组成宇宙裂隙通道。玩家完成恒星点火后，外部入口环依次点亮，恒星核心沿通道完成压缩和跃迁。

- 玩家三环全部完整后，先从共同水平面展开为三种不同轴向：内环顺时针、中环逆时针、外环以较慢速度顺时针旋转，形成浑天仪式坐标校准。
- 外部通道由 8 到 12 个半径一致或缓慢收束的圆环组成，保持清晰轴线和固定间距，与玩家浑天仪的共同中心环明确区分。
- 未解锁时外部圆环为低亮度橙红色，只显示锚点位置；达到质量要求后从入口到深处依次变为阶段色。
- 进入通道后，第一圈确认入口，后续外部圆环按跃迁进度逐个产生波纹和粒子；玩家浑天仪同步旋转测量坐标，穿过最后一圈后完成维度跃迁。
- 高维动画不是瞬间传送：镜头沿通道轴抬升，远处圆环压缩形成速度感，环境几何逐渐淡出，背景星线拉长，最后进入下一层结算。
- 进入 `ascending` 后由确定性的浑天仪姿态、飞升状态机和渲染进度接管，玩家移动与技能输入停止生效。


## AI 地图编排

AI 不直接输出数百个坐标，而是输出受 JSON Schema 限制的关卡配方。确定性程序生成器负责地形、道路、物体分布、碰撞和最终坐标。

```json
{
  "seed": 482193,
  "biome": "crystal_canyon",
  "objective": "collect_cores",
  "targetDuration": 300,
  "startMass": 1,
  "targetMass": 180,
  "layout": "spiral_islands",
  "zones": [
    { "tier": 1, "density": 0.75, "shapes": ["sphere", "cylinder"], "massRange": [0.2, 4] },
    { "tier": 2, "density": 0.55, "shapes": ["cube", "triangular_prism"], "massRange": [3, 30] }
  ],
  "hazards": ["pulse_wall", "rotating_beam"],
  "specialRules": ["low_gravity"],
  "palette": ["cyan", "coral", "lime", "white"]
}
```

同一 seed 必须生成相同地图，以支持分享、复盘和问题定位。

### 自动验证

`src/game/validator.js` 的 `validateLevel()` 已实现三项检查，输入是 `LEVEL` 基础数据（宇宙质量倍率取 1，最保守的情形）：

1. **必经目标可达**：在点火质量下，三枚锚点、糖心熔炉和裂隙出口必须从出生点可达。
2. **成长陷阱**：玩家在某个体型下能走到的每一格，长大之后必须仍能回到出口。这是高度跨越与窄门引入的新失败模式——"穿过窄门再长大"会把自己永久关在里面。
3. **贪心见证**：每步吃掉可达且吃得下的最轻目标，证明至少存在一条能完成点火的合法顺序，并返回该顺序供复盘。

网格只在质量阈值处变化，因此不必逐质量枚举。阈值来自各障碍的 `massToCross(height)` 与各窄门的 `maxMass`，第一关为 0 / 13.3 / 18.5 / 32.9 / 45.5 / 61.4 / 170。

验证器的可达性判定刻意比寻路严格：寻路用 `nearestOpenCell` 向外搜索 6 环以容错，但验证不能这样——6 环足以跨过一道墙落进另一个连通域，把"被封死的目标"误判成可达。因此验证走 `targetReachable`，只接受目标格自身或紧邻一圈中真正被洪泛标记过的格。

验证器带两个反向用例：一个用窄门围出的口袋、一个被四面封死的核心，都必须被报出问题。没有这两个用例，一个永远返回"通过"的验证器和没有验证器等价。

以下检查项仍未实现：

- 出生点附近初级资源密度、每个成长阶段都有可吞噬目标的定量检查（贪心见证只证明存在一条通路，不衡量节奏）。
- 引力吸附不会隔墙取走关键资源的检查。
- 对象数量、绘制调用、引力查询与物理负载的设备预算检查。
- 坠落恢复点检查（当前地图没有坠落区）。
- 批量模拟玩家估计完成率、成长断点与平均时长。

### 局内导演

局内 AI 只在受控范围调整提示和资源：玩家停滞时增强附近目标光效，连续失败时补充成长资源或降低动态障碍速度，高水平玩家则获得隐藏核心和高风险捷径。导演不能修改已建立的碰撞和吞噬规则。

## 世界主题

1. 荧光庭院：平缓地形，教授滚动、吞噬和尺寸判断。
2. 晶体峡谷：三棱柱山体、悬崖和可破坏晶桥。
3. 圆柱森林：高低错落的柱体通过倒塌形成连锁道路。
4. 失重环城：环形轨道、局部重力和球形小行星。
5. 棱镜机械城：移动棱柱、脉冲门和大型机械核心。

不同章节必须改变空间结构和规则，而不只是替换颜色。

## 视觉与声音

背景使用深色低饱和空间，主体采用青绿、珊瑚红、酸性绿、白色和少量品红的多色荧光。可吞噬状态通过发光强度和轮廓共同表达，不能只依赖颜色。

玩家视觉采用稳定的五阶段进阶：初醒为银白核心与冰青边缘，虹彩开始转为淡紫，脉冲使用高饱和紫色和电蓝/品红环，星冠进入紫红与金粉高光，高维则为白色核心高光叠加紫青能量。五个视觉阶段映射到三层共鸣环：前三个关键质量区间负责生成三条完整环，星冠和高维强化第三环、核心和粒子，不继续增加环数。

普通移动和充能时，玩家三环保持共同中心、固定半径和同一水平轨道平面。环体始终完整，暗色轨道上的渐变能量沿周向流动并填充；升阶后不会出现半截新环。只有进入 `ascending` 时，三环才展开为不同轴向并正反旋转，形成浑天仪。小卫星、轨道刻度和能量流纹理属于后续表现增强，在对应功能实际实现前不作为当前 MVP 完成项。

阶段充能低于 70% 时保持稳定；达到 70% 后核心、壳体和圆环开始低频亮度呼吸，95% 后增强边缘高光与粒子密度。跨越环解锁阈值时触发一次白紫闪光和同心冲击波，下一完整环整体渐显，然后稳定开始新的渐变充能。

声音由滚动摩擦、几何碰撞、吸附、碎裂、连击音阶和核心共鸣组成。体积增大时逐步降低滚动音高并提高低频重量感。

## 长期进度

长期解锁集中于外观和横向能力，不永久提高初始体积。

- 球体外观、核心纹理、拖尾、吞噬特效和音效。
- 引力、动量、棱镜和稳定四类核心，各自改变吸附、速度、连击或碰撞特性。
- 新世界主题、特殊规则、每日 AI 种子、无尽模式和竞速排行。

## 技术架构

- React 负责 HUD、菜单、状态界面和生命周期。
- Three.js 负责 3D 渲染、稳定行星环、轨道卫星、引力粒子轨迹和飞升圆环通道；游戏状态不以网格位置为准。
- 纯 JavaScript 固定时间步模拟负责移动、质量、成长、障碍高度判定、窄道门槛、引力吸附资格、遮挡结果、吞噬和目标判定。
- MVP 使用解析几何碰撞；后续通过窄接口迁移到 Rapier。
- 引力查询采用空间网格或四叉树，只检查玩家附近实体，并设置每帧吸附上限。
- 引力遮挡使用简化射线与障碍包围盒相交测试，关键资源默认禁用自动吸附。
- 行星环轨道参数来自阶段配置，轨道中心、法线和半径保持稳定；卫星位置由固定时间和确定性相位计算。
- 飞升圆环通道参数包含轴线、圆环数量、半径、间距和逐环进度，渲染层从确定性 `ascensionProgress` 派生动画。
- 重复物体使用 InstancedMesh，对象池处理碎片、卫星和粒子。
- 远处区域暂停物理并按空间分区加载。
- AI 服务端只输出结构化配方，生成器与验证器保持确定性。

### 导航网格与寻路

`src/game/navigation.js` 把关卡压成占位格，是回放代理避障与后续死锁验证器的共同基础。纯函数、确定性，A* 的 tie-break 按格索引排序，不引入随机数。

- 网格覆盖 `LEVEL.bounds`，格边长 1，约 52 × 40 格。障碍按传入的导航半径膨胀，格中心落在膨胀区内即不可通行；地图外缘同样按半径封边。
- 网格随质量变化：当前体型跨得过去的矮墙不计入障碍，挤不过去的窄门则加入障碍。`crossSignature` 与 `gateSignature` 给出这两组开合状态，参与网格缓存键。
- 可破坏糖板与相位门**不算障碍**：它们由冲刺与相位处理，计入障碍会让寻路误判为死路。
- `nearestOpenCell` 处理起点或目标落在膨胀区内的情况（例如贴墙的糖果怪），否则寻路会直接失败并让代理卡死。
- A* 为八向移动，斜向要求两侧正交格都空，避免贴着墙角穿过缝隙。
- `simplifyPath` 折叠共线航点，`segmentBlocked` 提供直线可达性检查。

回放代理据此分两种行进方式：视野无阻时直奔目标，被墙挡住才沿路径行进。目标会移动（糖果怪逃跑），所以路径每 30 步重算一次，而不是只算一次。网格按量化到 0.25 的导航半径缓存，玩家长大跨过量化档位时才重建。

代理暴露 `stats()` 返回规划次数、失败次数、沿路径步数与直线步数，用于确认避障没有退化成死代码。第一关实测四个宇宙各规划 24 到 30 次、零失败，用时从 42.5 秒降到 39 秒左右——此前它一直在贴着墙磨。

### 机制缺口

- **引力抑制区未实现**：牵引资格已按质量比例判定，但"需要主动关闭引力或绕开区域"的抑制区尚未加入。

### 渲染缺口

- **体素边缘描线未实现**：面亮度分层已落地，方块之间的边缘描线尚未实现。描线需要着色器或额外的 `LineSegments`，目前只靠亮度差区分方块。
- **稳定度缺少屏幕级提示**：扣减已有独立的尖锐碎屑爆发与 HUD 警示色，但没有屏幕边缘闪烁一类的全局提示，快速移动时容易漏看。

- 空间索引每步重建三次（移动前、移动后、吞噬前）。20 个对象下重建成本远低于省下的遮挡采样，但对象规模上量后应改为增量更新。

### 未开工阶段

- 第三阶段剩余部分：每日种子未实现。三种布局模板已落地，生成关卡已可从顶栏"换一张图"进入实际游玩。

### 程序生成

`src/game/generator.js` 由 seed 配方生成关卡，`src/game/random.js` 提供唯一的确定性随机源（mulberry32，禁用 `Math.random`）。

核心思路不是"随机撒点再靠验证器筛"，而是让结构本身排除最难修的失败模式：

1. 先铺一条从出生点到出口的开放走廊，全程不放窄门——主干永远连通。
2. 墙体只放在离走廊足够远的位置（半对角线加 6 单位余量），绝不横断主干。
3. 窄门只架在"走廊上绕得很远、空间上却很近"的两点之间，因此它永远只是捷径。关掉任何窄门都不会切断通路，成长陷阱在结构上不可能出现。
4. 对象沿走廊按质量升序分布，成长链天然成立；燃料摊在靠后的多个对象上，漏掉最大来源仍能凑满。

验证器仍然每次都跑，但角色是护栏而非筛子。实测 60 个连续种子全部通过，平均 1.70 次尝试。

墙体高度取自成长阈值阶梯（1.9 / 2.7 / 3.5），25% 概率生成 `unclimbable` 高墙。质量曲线陡缓与总预算随 seed 浮动——否则每张图的成长阶梯完全一样，"程序生成"就只剩换墙位和换配色。60 个种子给出 37 种不同总质量。

`levelMetrics` 输出速览指标：模板名、对象数、总质量与点火余量、总燃料、燃料来源数、漏掉最大来源后的余量、墙与窄门数量、各墙的跨越质量阈值。

### 布局模板

三种模板各自只负责生成中间折点，起点与出口由配方固定，因此"对象沿走廊按质量升序分布"、"墙体离走廊足够远"、"窄门只设下限"这三条不变量在三种模板下都照样成立。模板由 seed 决定，换图会换骨架而不只是换墙位与配色。

- 走廊型：起点直奔出口，中段侧向摆动。绕行倍数约 1.1，平均放下 4 道墙。
- 折返型：横向来回摆到两侧极限，纵向单调推进。绕行倍数约 3.9，捷径窄门在这种图上才真的是捷径。
- 螺旋型：绕地图中心由外向内盘 1.5 圈，最后一段接到出口。绕行倍数约 2.2，平均 3.5 道墙。

墙体离走廊的余量按模板给（走廊型 6、螺旋型 5、折返型 3.5）。折返型的走廊来回扫过整张图，套用走廊型那套余量就几乎没地方放墙——实测平均只放下 0.6 道，"再吃一个就能翻过去"这条反馈在那种图上等于不存在；调到 3.5 后回到 1.6 道。余量下限受寻路半径约束：`MAX_NAVIGATION_RADIUS` 是 2.35，取 3.5 仍留 1.15 的富余。折返型的墙数仍明显少于另两种，这是它走廊扫过全图的必然结果。

实测 60 个连续种子全部生成成功、平均 1.02 次尝试、三种模板都出现；每种模板各取 12 个种子，自动演示全部打到点火与裂隙，零个对象被封死。

窄门必须在锚点与核心确定之后才放置。低质量下窄门是关着的，若窄门压在锚点上，早期就够不到那个锚点——这是早期实测中 12/30 个种子失败的唯一原因。

生成关卡的窄门只设 `minMass`，不设 `maxMass`。带上限的窄门会随玩家长大而关闭，而这些窄门的落点几乎必然压在主干走廊上——实测 40 个种子的 73 道窄门，73 道全压在走廊上，一关就把那段走廊上的对象永久封死，40 个种子全部出现 2 到 8 个对象在点火质量下不可达。验证器没报警，因为它只检查锚点、核心与出口这些必经目标。只留下限后可达范围随质量单调增长，封死在结构上不可能发生；双侧约束留给手工关那种"窄门开在实墙上"的布局。

`minMass` 由捷径近端之前那些对象的质量总和算出（40% 到 75%），保证门槛付得起。直接取随机区间会造出"必须吃到门后面的东西才够"的门槛，那就是成长陷阱——实测 40 个种子里有 3 个因此完全生成不出关卡。

自动演示的路线随关卡派生：`routeForLevel` 在关卡含有手工路线引用的对象时用手工路线，否则按质量升序生成（`deriveRoute`），顺序与验证器贪心见证一致。单个可吞噬目标有 30 秒步数预算，超时就挪到路线末尾等回头再吃。实测 12 张连续种子的生成关卡全部由自动演示打到点火与裂隙。

顶栏"换一张图"按 `SHUFFLE_STRIDE = 977` 向前推进种子并整场重建：关卡静态几何在 `createScene` 建场时一次性铺好，因此换图不是运行时切换而是重建场景（`useEffect` 依赖 `slot.level`）。生成失败时保留当前关卡并在状态行报错，绝不把关卡置空。`nextMapSlot` 是纯函数，因此换图判定能被单独验证——渲染层本身拿不到自动化覆盖。

- 锚点记账：`encounter.anchors` 已移除，锚点状态只保存在 `state.anchors`。
- 糖果怪碰撞：糖果怪与被牵引碎片已接入边界钳制与障碍推出。

- 尺寸口径：视觉半径、吞噬半径与导航半径的关系已明确记录，见“尺寸口径决策”。
- 体素几何：玩家糖心、五类糖果怪、糖核锚点、糖宠本体与糖屑粒子已全部改为体素网格，内部面剔除，几何按形状缓存复用。

- 高度跨越与窄门：`passageHeight` 已接线，障碍高度阶梯对齐成长阈值，窄门带质量上限，模拟层按质量决定是否碰撞。"成长导致过道永久关闭"这条核心策略现已成立。
- 门槛标注：障碍显示 `H x.x`、窄门显示 `≤N`，够格转暖色、不够保持暗灰；HUD 增加当前通行高度。
- 导航网格随质量变化：矮墙在体型足够时从网格中消失，窄门在体型过大时加入网格，缓存键包含跨越与开合签名。
- 阶段化死锁验证：`validateLevel()` 检查必经目标可达、成长不会把玩家关进与出口断开的区域，并用贪心见证给出一条可完成点火的合法顺序。带两个反向用例保证检出能力。
- 牵引资格按质量比例：`canPull` 取代 `gravity: true` 白名单，上限为玩家质量的 18%，糖心熔炉永不参与。
- 牵引遮挡完整：跨不过去的墙、关闭的窄门、未破坏的糖壳板与糖雾门都会阻断牵引，与跨越规则一致。
- 高墙显式声明：`unclimbable` 标记取代"靠高度数值挡住"，因为质量无上限，任何有限高度都会被足够大的体型翻过去。
- 渲染派生可测：标签文本与颜色、窄门开合外观、情绪倾斜抽到 `readout.js`，`createScene.js` 只剩无法测试的 three 调用。
- 评价维度补全：燃料纯度与全程最低稳定度已进入结算并参与星级判定，"点火零失稳给三星"从文案变成规则。
- 空间索引与吸附上限：`spatial.js` 均匀网格让牵引、吞噬、糖果怪三处只遍历邻域（实测平均 1.5 个对象对全表 19 个），`MAX_PULLS_PER_STEP` 限制单帧牵引数。四个宇宙回放结果逐项不变。
- 窄门双侧门槛：`minMass` 补上"质量不足推不开"，标签按 `≤N` / `≥N` / `N–M` 三种形式区分；`gate-core` 以 12–60 的有限时窗贯穿南侧高墙。
- 关卡参数化：`navigation.js` 与 `validator.js` 接受 `level` 参数并默认为 `LEVEL`，因此验证器可以检查生成的关卡而不只是首关。
- 种子生成器：`generator.js` 由配方生成关卡并自动验证，结构上排除成长陷阱，60 个连续种子全部通过。
- 生成关卡可玩：关卡是建局参数而非模块级常量，`createScene(host, level)` 与顶栏"换一张图"让生成的图真正进入游玩。
- 单调窄门：生成关卡的窄门只设下限，可达范围随质量只增不减；新增用例逐质量采样，可达对象数掉一个就报错。
- 布局模板：走廊型、折返型、螺旋型三种骨架由 seed 选定，绕行倍数分别约 1.1 / 3.9 / 2.2。

## MVP 验收标准

以下是完整目标清单，其中依赖高度障碍、窄门标注、质量比例吸附和空间分区的条目当前不成立，对照“实现状态”判断。

- 新玩家一分钟内无需阅读长说明即可理解主动吞噬、引力吸附和数字门槛。
- 一局至少出现四次清晰的体型突破。
- 固定地图不存在成长断点或永久卡死路线；存在至少一条"只变大不回头"的通关路线。
- 玩家能在不暂停的情况下通过数字标签判断哪些物体可吞、哪些障碍可跨越、哪些过道即将关闭。
- 阶段充能环在充能、满格、跃迁三个状态间表现清晰，玩家可据此决定是否升级。
- 行星环保持同心稳定，能量流与小卫星沿固定轨道旋转，升阶不产生轨道位置跳变。
- 引力只吸附满足比例且无遮挡的小型碎片，不会隔墙吞噬或破坏迷宫唯一解。
- 不同高度的障碍至少能通过成长跨越、绕行或机关解除其中一种方式解决。
- 飞升入口由清晰的多圆环通道组成，达到条件后依次点亮并完整播放穿越动画。
- 镜头不穿模，不被大型物体长期遮挡；大体积时视野仍能看到前路和过道标签。
