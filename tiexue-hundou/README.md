# 铁血魂斗

手机触屏横版跑射（run & gun）。魂斗罗式的八向射击、一击死、捡枪换火力，
但**弹药只从命中里来**：枪是自动开火的，弹匣打空只能装回 5 发而且很慢，
打中人回 1 发、打中 Boss 的核心舱回 2 发、打在装甲上一发不回。
于是「站远了扫射」是最先把自己饿死的打法。

## 玩法

- **自动开火**：站着就一直在打。手上只有三件事——往哪走、往哪瞄、跳不跳。
- **八向射击**：上／斜上／平射，空中按下是压枪。地面按下是**蹲下**：停火、变矮、
  并且用两倍速度把弹匣补回底数。这是这游戏唯一的喘气动作，代价是蹲着不能动。
- **一击死**：挨一发子弹、被人撞上、踩进水里都是一条命。重生只带一个底数弹匣，
  枪也掉回制式步枪——**捡到的火力是一次投资，不是永久收益**。
- **补给箱**：打爆会掉散弹枪／机枪／穿甲激光／弹药箱。散弹一次扣 2 发弹药却吐出 3 颗子弹，
  三颗都能各自回弹，所以贴身打散弹是唯一能让弹匣「越打越满」的开法。
- **钢架**：单向平台，从下面能跳上去，按住下键再跳能漏下去。
- **关末那台机器**：核心舱开 2.4 秒、闭 1.5 秒。闭合时打上去只有一声闷响，一发不回弹、
  还把连击清零；开着的时候它的弹幕也更密——**能打的那一拍就是最难站的那一拍**。

## 八关

弯的不是数值而是压迫方式：兵力、炮台数、Boss 血量、地形垂直度四个旋钮一路往上。

1. `1-1` 丛林突入 — 几乎平的一条路，教三件事：往右压、跳过灌水的坑、打爆补给箱
2. `1-2` 钢架桥道 — 平台成段出现，跳兵会跨上来
3. `2-1` 废弃基地 — 箱子是掩体也是障碍，两座炮台从高处封走位
4. `2-2` 瀑布垂降 — 平台叠成两层，第一次需要空中压枪
5. `3-1` 雪原铁路 — 冲锋兵登场：不开枪，只往身上撞
6. `3-2` 能源工厂 — 三层结构，炮台架在中层
7. `4-1` 要塞回廊 — 四座炮台把走廊切成一格格的射界
8. `4-2` 魂斗核心 — 前面教过的全上一遍，Boss 血量是第一关的三倍半

## 运行

```bash
npm run dev:tiexue-hundou     # http://127.0.0.1:4199
npm run test:tiexue-hundou
npm run build:tiexue-hundou
```

键盘：方向键／WASD 走位与瞄准，空格／Z／J／K 跳，Esc／P 暂停。
触屏：左半屏摇杆（横着拖走位、竖着拖瞄准），右半屏点一下跳、按住跳更高。

## 结构

- `src/game/` — 没有 DOM 的判定层，可以整局跑测试
  - `rules.js` 全部可调数值，弹药经济的三个数（`AMMO_MAX` / `RELOAD_FILL` / `REFUND_*`）都在这里
  - `tiles.js` 关卡字符画的含义与解析；`levels.js` 八关的字符画与难度指标
  - `physics.js` 分轴碰撞与单向平台；`weapons.js` 枪械表与八向瞄准
  - `entities.js` 三种兵、炮台、Boss 与掉落；`simulation.js` 一帧的全部推进
- `src/scene/` — 只读状态的表现层：`render.js`（Canvas 2D）、`audio.js`（WebAudio 现场合成）、
  `readout.js`（把数字翻成 HUD 文案）
- `test/` — `node --test`

## 测试守着什么

- **机器人通关**（`playthrough.test.js`）：一个只会「往右压、遇坑跳、见弹跳、弹匣空了趴下换弹」
  的机器人跑完八关，守「每关都过得去」。
- **玩法经济**（`economy.test.js`）：把命中回弹整局关掉跑对照组，同一个机器人打同一台 Boss
  会慢 1.5～2.8 倍；把「往前压」掐掉则八关都打不完。**这两条是这游戏成立的前提**，
  不是锦上添花的断言。
- **音效语义**（`audio.test.js`）：相反的处境不许响成同一声——命中回弹是上行滑音，
  打在装甲上是下坠闷响；空仓和装填完成也是一上一下。
- **难度曲线**（`levels.test.js`）：兵力和炮台一路不降、Boss 血量一路走高，
  坑一律不超过 3 格宽，布点不许悬空。
