# 方块疾风 · Voxel Dash

3D 体素风无尽跑酷。三条车道、四种障碍、越跑越快，操作为手机触屏优先。

## 玩法

- 左右滑动变道，上滑或轻点跳跃，下滑滑铲；空中下滑会立刻砸向地面并接上滑铲。
- 木箱要跳过，横杆要滑铲，整面墙只能变道，地面缺口靠跳跃跨过。
- 连续吃金币叠加连击倍率（最高 4 倍），磁吸吸附邻道金币，护盾抵挡一次撞击。
- 距离越远速度越快，并依次穿过翠原、流沙、霓虹、虚空四个区域。

## 反馈

跑酷全靠手感，此前一路上一声都没有：吃到金币、被护盾挡下、直接撞毁，感官上完全一样。
现在每个动作都有一声，全部由 WebAudio 现场合成，不引任何音频文件。

- **变道**是全表最轻的一声（只有一层高通白噪）：一局要响几百次，压到只剩轮廓才不吵。
- **金币越串越高**：一条音色配 `STREAK_SHIFTS` 半音表，连吃到第八颗封顶，再往上就刺耳了。
  磁吸会把一排金币同一帧全吸过来，取串得最长的那一枚，那才代表现在的势头。
- **护盾挡下和撞毁一听就分得开**：护盾是高频金属挡格，撞毁是低频炸开再下坠。
  「刚才那下没死」是这游戏最需要立刻确认的一件事，所以护盾排在道具和金币之前。
- 撞毁那一声独占这一批，脚步和金币不会盖在上面；其余情况一帧最多出 `MAX_PER_BATCH` 声。
- **触感**只在护盾挡下和撞毁两个关口给，全程都震手会麻。
- 右下角可静音，偏好写进 `localStorage`；静音开局连 `AudioContext` 都不建。
- 结束面板：破纪录挂「新纪录」徽章（拿开局那一刻的旧纪录比，不是拿已经被本局刷过的
  `best` 比），星星逐颗弹出来，下面一句 `rewardLabel` 说清下次往哪使劲。
- 所有动效都在 `prefers-reduced-motion: reduce` 下停掉。

## 结构

`src/game/` 是纯逻辑层，不引用 Three.js：`rules.js` 定义体积与判定，`track.js` 由 seed
生成跑道分段，`validator.js` 逐排推进可达车道集合确认没有死局，`simulation.js` 是固定
步长主循环，`input.js` 把键盘和触摸归一成一次性输入。

`src/scene/` 是渲染层，不写回模拟状态：`voxel.js` 烘体素网格并剔除隐藏面，
`createScene.js` 负责相机、实例化障碍与金币，`readout.js` 派生 HUD 文案，
`audio.js` 里 `SOUNDS`／`soundsFor` 是纯数据与纯函数（能在 node 里单测），
只有 `createAudio` 碰 `AudioContext`，且第一次真要出声时才建。

这条边界是确定性回放和单元测试的前提：同一个 seed 加同一串输入，模拟结果逐字段一致。
