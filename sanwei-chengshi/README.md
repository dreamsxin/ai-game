# 三维城市 · 仿真城市地图生成器

一个 seed 就是一座城。输入 seed（或直接敲城市名）生成完整的三维仿真城市：河道、路网分级、
用地分区、按天际线规律排布的楼宇，以及可点选查询的楼宇档案和搜索定位。

```bash
npm run dev:sanwei-chengshi     # http://127.0.0.1:4183
npm run test:sanwei-chengshi
npm run build:sanwei-chengshi
```

## 怎么用

- **换城**：改 seed 后点「生成」，或点骰子随机。同一个 seed 永远长出同一张地图。
- **尺度**：小城 64×64、新城 96×96、都会 128×128 格，一格 10 米。
- **看城**：拖拽旋转、滚轮/双指缩放、右键拖拽平移。
- **查楼**：点任意一栋楼，右下角信息卡给出用地性质、层数、高度、门牌号。
- **搜索**：楼名、门牌、用地性质都能搜，点结果镜头直接飞到楼前并亮起光柱。

## 生成流程

`generateCity(seed, scale)` 是唯一入口，六步串成一条流水线（`src/game/city.js`）：

1. `terrain.js` — 随机行走出一条贯通两岸的河，河心带漂移所以会出现大弯。
2. `roads.js` — 整块用地按「长边随机切一刀」递归二分。刀口就是道路（深度决定
   主干道/次干道/支路），切剩的矩形直接就是街区，所以路网天然连通、街区天然闭合，
   不需要事后修补连通性。
3. `naming.js` — 按等级给道路起名（大道/路/街），重名挂「二段」，保证全城无重名。
4. `blocks.js` — 按离城心的距离 + 水面比例给街区定性：核心 CBD、商务、商业、住宅、
   产业园、绿地、水域。
5. `buildings.js` — 街区退让人行道后切宅基地，逐格按覆盖率决定盖不盖；层数由距离衰减
   （平方）主导，随机只在区间内抖动，天际线因此从核心往外递减。核心区最高的一栋标为地标。
6. 建索引与统计 — 逐格 `lookup` 支撑点选，`stats` 汇总面积、里程、总建面、用地构成。

## 分层约定

- `src/game/` 纯数据与算法，不引 three.js、不碰 DOM，所以能直接用 `node --test` 断言。
  随机数只有一个来源：`random.js` 的 seed PRNG。
- `src/scene/` 只读城市数据往屏幕上画，从不回写。地面是一张按格生成的 `DataTexture`
  （水域/路网/用地一次画完），楼宇是单个 `InstancedMesh`——都会级两万多栋也只是两个
  draw call 级别的开销。`instanceId` 与 `city.buildings` 下标一一对应，点选就靠这个约定。
- `test/` 与模块一一对应，覆盖确定性（同 seed 同结果）、街区不重叠不压路、
  楼不越界不下水、层数区间、统计口径自洽。
