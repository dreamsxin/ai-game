# 旋风卡丁

手机触屏漂移竞速。QQ 卡丁车式的手刹过弯与氮气喷射，但这游戏的身份是一条经济关系：

> **氮气是唯一的硬通货，而它只能从弯里攒出来。**

一条完整的收益链是：拉手刹横着过弯（付一点速度）→ 攒到一档气 → 在直道上喷掉（拿回一大段）。
链子走完才赚，**走一半反而亏**——「漂了不喷」是这游戏里最慢的开法，比一路抓地还慢。
所以弯道不是障碍，是产地；直道不是休息，是兑现的地方。

```bash
npm run dev:xuanfeng-kading     # http://127.0.0.1:4195
npm run test:xuanfeng-kading
npm run build:xuanfeng-kading
```

## 怎么玩

- 油门一直全开，**没有刹车**。手机上只有三个操作：方向、手刹、氮气。
- 方向是模拟量：屏幕任意处横向拖动（或左右两颗按钮／键盘方向键），**打多深决定漂多横**。
- 手刹（Shift／屏幕「手刹」键）过弯。松手结账：气够一档就存进右下角的三格，不够就白漂。
- 氮气（空格／屏幕「氮气」键）按一次喷一发，取手上最大的那一档。
- **松手后半秒内再入漂＝连喷**，新的一段带着底气开始，喷出来的音高会一路往上爬。
- 读秒最后 0.55 秒按氮气是**弹射起步**；早按一帧就是抢跑，罚站 0.9 秒。
- 名次达标才算过关，三次机会。时限存在只是为了兜住「一路冲进草地」，不是主要压力。

## 五条贯穿全局的规则

1. **漂移角是主动量，不是失控的后果**。车头（`heading`）与速度方向（`course`）分开算，
   拉手刹时速度方向去追「车头往回让出一个漂移角」的方向，方向盘打多深就甩多横。
   攒气速率跟着漂移角和车速走，所以缓弯里想攒气就得**主动多打一点方向**，代价是走线更宽。
2. **攒气有上限（`CHARGE_MAX` 1.25），氮气有三格**。一直横着不松是新手最常见的亏法：
   气早就顶到头，多漂那几秒一分钱没多攒。攒到大喷就该松手落袋、再拉回来接连喷。
3. **喷射是回报端**：上限 50 m/s，比抓地上限高近五成，大喷持续 1.8 秒。
   这个数是玩法参数而不是手感参数——实测调回 46 附近，弯多的那几关就会翻盘成
   「一路抓地不漂反而更快」，攒气随之失去意义。`playthrough.test.js` 守着这一条。
4. **草地是持续的亏，撞墙是一下的痛**。压上草地上限掉到 13 m/s，而且**在草上漂移是漏气**；
   冲出缓冲带才算撞墙，速度砍半、车头被掰回赛道方向（否则会贴着墙磨一路）。
5. **尾流**：贴在别人车尾 14 米内白拿 8% 上限。玩家永远发在最后一排，
   这是唯一的免费资源，也是「跟车 → 出弯超掉」这条节奏的来源。

## 八条赛道递进的是弯道密度，不是数值

赛道中心线用极坐标的谐波和写成 `r(θ) = R · (1 + Σ aₖ·sin(kθ + φₖ))`（见 `src/game/course.js`）：
闭合是白送的，不用手工对齐首尾，而「弯道密度」正好落在阶数 k 和振幅 a 上。
`src/game/tracks.js` 里每关只有四个旋钮：**弯道密度、路面宽度、圈数、对手档位**，名次门槛跟着收紧。

从「环湖热身」到「旋风终盘」，四个旋钮各走一段：

- 最紧的弯心半径 66 米 → 16 米（全速抓地画不出来的弧越来越多）。
- 路面宽度 30 米 → 24 米，圈数 2 → 3。
- 对手 3 → 5 车，档位 0.3 → 0.78。
- 名次门槛 前 3 名 → 前 2 名 → 冠军。

时限不手写，按赛道长度反推（`buildLevel`）：改宽改弯之后不用回来对时间。
`tracks.test.js` 守着「平均曲率一路走高、最紧的弯一路更紧、路面只窄不宽、门槛只紧不松」。

## 判定层与表现层

`src/game/` 没有 DOM，也没有随机源以外的不确定性；`src/scene/` 只读状态。

- `course.js` 赛道几何（等弧长节点表、投影、前瞻曲率），判定／机器人／渲染／小地图共用同一份。
- `kart.js` 一辆车的全部判定：漂移、攒气、喷射、草地、撞墙、擦碰、计圈。人和机器人走同一个函数。
- `bots.js` 机器人大脑，**一个 `skill` 参数**。低档的笨长在三个具体决策上：忘了漂、乱喷气、抢跑。
- `simulation.js` 一局比赛的状态机：读秒（弹射判定在这里）、名次、完赛、结算。
- `scene/audio.js` 程序化音效 + 常驻引擎声；`scene/readout.js` 全部界面文字；`scene/render.js` 跟着车头转的俯视图。

## 测试守着什么

`node --test test/*.test.js`，64 条。除了几何和状态机，有三组是玩法本身的守门人：

- **每关都过得去**：满档大脑接管玩家跑完八关，每关六个 seed 至少达标一次。
- **档位真的是难度**：同一关同一批 seed 只换对手档位，过关次数必须明显不同；
  低档会抢跑、会把气烂在弯里，满档不会。
- **经济关系还成立**：把玩家的某一路操作掐掉跑对照组（`test/arena.js` 的 `allow` 参数），
  八关都必须满足「漂移+喷 < 一路抓地 < 漂了不喷」。这一组是这个游戏之所以是这个游戏的原因。

音效那一组守的是**语义**而不是好不好听：超掉别人／被别人超掉、弹射起步／抢跑罚站、
攒成一档／白漂一段——三对相反的处境不许响成同一声。
