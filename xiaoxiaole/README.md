# 甜果消消乐 · 三消

手机触屏优先的三消游戏。8x8 棋盘、交换匹配、连锁下落，四连出直线爆果、L/T 形出爆破果、五连出彩虹果，五关递进。

## 玩法

- 棋盘上拖动一颗果实到相邻位置换位，也可以点一下选中、再点旁边那颗交换。
- 键盘：方向键移动光标，`Space`/`Enter` 选中后再按方向键换位，`Esc`/`P` 暂停。
- 三颗同色即消，消除后果实下落补充，一次操作引发的连续消除按连锁计数，倍率从 1 倍每环加 0.5，最高 4 倍。
- 四连留下直线爆果（横向消整行、纵向消整列），L/T 形留下爆破果（炸周围九格），五连留下彩虹果（带走全场同色）。
- 特殊果实换到哪都能引爆，不需要凑三连；两颗彩虹果换在一起直接清空整盘。
- 每关限定步数，达到目标分即过关，星级按三档门槛结算。棋盘走成死局会自动洗盘，不消耗步数。

## 本地运行

```bash
npm run dev:xiaoxiaole   # http://127.0.0.1:4179
npm run test:xiaoxiaole
npm run build:xiaoxiaole
```

## 结构

`src/game/` 是纯逻辑层，不碰 DOM：`tiles.js` 定义六种果实与形状到特殊果实的奖励规则，
`board.js` 管消除识别、引爆扩散、下落补充与洗盘，`levels.js` 是五关的步数与目标，
`rules.js` 定义计分与各阶段时长，`simulation.js` 是固定步长的阶段状态机
（idle → swap → clear → fall → 再判定），`input.js` 把键盘和手势归一成同一份输入，
`layout.js` 是渲染与输入共用的格子换算。

`src/scene/` 是表现层，不写回模拟状态：`render.js` 用 Canvas 2D 画棋盘、果实、特殊标记和消除爆开，
`readout.js` 派生 HUD 文案与进度。

这条边界让确定性回放成立：同一个 seed 加同一串输入，模拟结果逐字段一致，测试因此不需要浏览器。
`test/playthrough.test.js` 让贪心机器人把五关各打三个 seed，关卡目标一旦调成过不去就会被测出来。
