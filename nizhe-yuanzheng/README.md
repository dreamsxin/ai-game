# 泥辙远征 · Mudhaul

硬核越野卡车模拟。地图 512×512 米，三趟运输任务，重点不是快，而是能不能到。

```bash
npm run dev:nizhe-yuanzheng   # http://127.0.0.1:4186
```

## 玩法

- `1/2/3/4/5` 挡位：倒挡 / 空挡 / 自动 / 低速 / 爬行。泥地里用低速和爬行挡。
- `W/S` 油门刹车，`A/D` 方向，`Space` 手刹。**轮子一空转就没有推力**，把「打滑」读数压在半格以下。
- `F` 四驱，`G` 差速锁。开放差速器会被打滑的那一侧卡住，锁上才能把扭矩送到有抓地力的轮子上。爬行挡自动锁差速。
- `E` 挂绞盘到附近的树或石头，按住 `Q` 收线。陷车之后这是唯一的正经出路。
- `C` 装卸货（要停稳），`V` 加油，`T` 叫拖车（罚时 60 秒），`B` 切镜头，`H` 玩法，`R` 重开。
- 手机上：左下角方向、右下角油门刹车和收线，其余操作在左右两侧的按钮里。

## 为什么会陷车

车辙是这个游戏的记忆体。轮子压过软地就会留下车辙，**只增不减**，而车辙又让下一次陷得更深：

- 接地压强除以地面承载力决定下陷深度，所以满载比空载陷得多，窄胎比宽胎陷得多。
- 下陷同时抬高推泥阻力、压低摩擦系数。新鲜的深泥沼还爬得动，被自己碾过三趟的同一片泥沼就是个坑。
- 打滑的轮子挖车辙比滚过去快一个数量级。原地焖油门是把自己埋进去最快的办法。

因为货比车厢多，第二关和第三关都得跑两趟——第二趟走的是自己第一趟压出来的坑。

## 三趟任务

- **木料上山**（山猫 S3，轻型四驱）：两捆木料，中段一片泥路。教下陷和挡位。
- **沼泽钢管**（塔戈 T6，三轴六驱）：四捆钢管，车厢只装三捆。教差速锁和绞盘。
- **变压器过河**（磐石 K9，重型牵引）：六件变压器，一次装四件。涉水、长上坡、高重心。

## 结构

```
src/game/    模拟层，不引用 Three.js
  vec.js         向量与四元数（航向约定：forward = (sin yaw, 0, -cos yaw)）
  random.js      确定性 PRNG 与值噪声
  rules.js       物理常量与地面材质表
  trucks.js      三台车的规格
  terrain.js     高度场生成、采样、车辙
  level.js       路线、货场、加油点、道具索引
  powertrain.js  扭矩曲线、挡位、差速器分配、油耗
  tire.js        滑移率、摩擦圆、下陷与阻力
  vehicle.js     六自由度刚体 + 每轮射线悬挂
  winch.js       绞盘
  cargo.js       货物质量与重心抬升
  simulation.js  顶层状态机与离散操作
  input.js       键盘/触屏归一化
src/scene/   渲染层
  camera.js      跟随相机（纯数学）
  parts.js       车身部件描述（纯数据）
  readout.js     HUD 文案与仪表快照
  createScene.js 唯一引用 Three.js 的文件
```

模拟层不引用 Three.js，渲染层不写回模拟状态。这条边界是单元测试的前提。

刚体以 1/120 秒定步长推进，所以 `step()` 原地修改 state 并返回同一个对象——每个子步都造新对象会把 GC 压垮。HUD 由 `readout()` 现算快照。

## 验证

```bash
npm run test:nizhe-yuanzheng
npm run build:nizhe-yuanzheng
```

`test/drive.test.js` 会用无头自动驾驶把三趟任务各跑一遍。物理参数一改动，最先在这里出问题——它拦住的是「数值没炸，但车已经谁也开不动了」这类回归。
